# 练习 9.1

*目标：*

- 复习模块基础

本练习介绍库模块的一些较难细节。先创建非常简单的库模块：

```python
# simplemod.py

x = 42        # A global variable

# A simple function
def foo():   
    print('x is', x)

# A simple class
class Spam:
    def yow(self):
        print('Yow!')

# A scripting statement
print('Loaded simplemod')
```
    
## (a) 模块加载与系统路径

尝试导入刚创建的模块：

```python
>>> import simplemod
Loaded simplemod
>>> simplemod.foo()
x is 42
>>>
```
    
如果出现 `ImportError`，说明路径设置有问题。检查并修复 `sys.path`。

```python
>>> import sys
>>> sys.path
... look at the result ...
>>>
```
    
## (b) 重复加载模块
    
确保理解模块只加载一次。尝试重复导入，注意不会再次看到 `print` 的输出：

```python
>>> import simplemod
>>>
```

修改 `x`，观察重复导入对它没有影响。

```python
>>> simplemod.x
42
>>> simplemod.x = 13
>>> simplemod.x
13
>>> import simplemod
>>> simplemod.x
13
>>>
```

如需强制重新加载，使用 `importlib.reload()`。

```python
>>> import importlib
>>> importlib.reload(simplemod)
Loaded simplemod
<module 'simplemod' from 'simplemod.py'>
>>> simplemod.x
42
>>>
```
    
`sys.modules` 是包含所有已加载模块的字典。查看它，删除你的模块，然后再次导入。

```python
>>> sys.modules
... look at output ...
>>> sys.modules['simplemod']
<module 'simplemod' from 'simplemod.py'>
>>> del sys.modules['simplemod']
>>> import simplemod
Loaded simplemod
>>>
```

## (c) from module import

重启 Python，从模块中导入一个指定符号。

```python
>>> ############### [ RESTART ] ###############
>>> from simplemod import foo
Loaded simplemod
>>> foo()
x is 42
>>>
```

注意，整个模块都被加载了：观察 print 的输出以及 `x` 的使用方式。

使用 `from` 时，模块对象本身不可见。例如：

```python
>>> simplemod.foo()
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
NameError: name 'simplemod' is not defined
>>> 
```

确保理解：从模块中导出的内容只是名称引用。例如，试试以下代码并解释结果：

```python
>>> from simplemod import x,foo
>>> x
42
>>> foo()
x is 42
>>> x = 13
>>> foo()
x is 42                   # !! Please explain
>>> x
13
>>>
```

## (d) reload() 的问题

创建一个实例：

```python
>>> import simplemod
>>> s = simplemod.Spam()
>>> s.yow()
Yow!
>>>
```

打开 `simplemod.py`，将 `Spam.yow()` 的实现修改为：

```python
# simplemod.py
...

class Spam:
    def yow(self):
        print('More Yow!')
```

现在观察重新加载后的结果。本部分不要重启 Python。

```python
>>> importlib.reload(simplemod)
Loaded simplemod
<module 'simplemod' from 'simplemod.py'>
>>> s.yow()
'Yow!'
>>> t = simplemod.Spam()
>>> t.yow()
'More Yow!'
>>>
```

注意，两个 `Spam` 实例使用不同的 `yow()` 实现。确实，两版代码同时加载在内存中。还会发现其他奇怪现象，例如：

```python
>>> s
<simplemod.Spam object at 0x1006940b8>
>>> isinstance(s, simplemod.Spam)
False
>>> isinstance(t, simplemod.Spam)
True
>>>
```

因此，重要功能最好不要依赖重新加载。调试时或许可以使用，但必须了解它的限制和风险。
