# 练习 3.1

*目标：*

- 定义简单的类

*修改文件：* `stock.py`

[练习 1.5](ex1_5.md) 定义了表示股票持仓的简单类 `Stock`。本练习为该类添加几个功能，并编写一些工具函数。

## (a) 添加新方法

给 `Stock` 添加 `sell(nshares)` 方法，通过减少股数来卖出指定数量的股票。它应支持以下用法：

```python
>>> s = Stock('GOOG',100,490.10)
>>> s.shares
100
>>> s.sell(25)
>>> s.shares
75
>>>
```

## (b) 读取投资组合

在 `stock.py` 中添加 `read_portfolio()` 函数，将投资组合数据文件读入 `Stock` 对象列表。用法如下：

```python
>>> portfolio = read_portfolio('Data/portfolio.csv')
>>> for s in portfolio:
        print(s)

<__main__.Stock object at 0x3903f0>

```

[练习 2.3](ex2_3.md) 已编写过类似函数。设计讨论：`read_portfolio()` 应是独立函数，还是类定义的一部分？

## (c) 输出表格

用 (b) 部分读取的数据生成格式美观的表格。例如：

```python
>>> portfolio = read_portfolio('Data/portfolio.csv')
>>> for s in portfolio:
           print('%10s %10d %10.2f' % (s.name, s.shares, s.price))

        AA        100      32.20
       IBM         50      91.10
       CAT        150      83.44
      MSFT        200      51.23
        GE         95      40.37
      MSFT         50      65.10
       IBM        100      70.44
>>>
```

将此代码放入 `print_portfolio()` 函数，输出相同内容，并额外添加表头。例如：

```python
>>> portfolio = read_portfolio('Data/portfolio.csv')
```
