# 练习 7.5

*目标：*

- 创建第一个元类

*新建文件：* `mymeta.py`

## (a) 创建第一个元类

创建 `mymeta.py`，写入以下来自幻灯片的代码：

```python
# mymeta.py

class mytype(type):
    @staticmethod
    def __new__(meta, name, bases, __dict__):
        print("Creating class :", name)
        print("Base classes   :", bases)
        print("Attributes     :", list(__dict__))
        return super().__new__(meta, name, bases, __dict__)

class myobject(metaclass=mytype):
    pass
```

接着定义一个继承 `myobject` 而非 object 的类。例如：

```python
class Stock(myobject):
    def __init__(self, name, shares, price):
        self.name = name
        self.shares = shares
        self.price = price
    def cost(self):
        return self.shares * self.price
    def sell(self, nshares):
        self.shares -= nshares
```

运行代码并创建 `Stock` 实例，观察结果。应该在定义 `Stock` 时看到 `mytype` 的输出语句执行一次。

如果继承 `Stock`，会怎样？

```python
class MyStock(Stock):
    pass
```

仍然可以看到元类在工作。元类具有“黏性”，会应用到整个继承层次。

**讨论**

为什么要这样做？元类的主要能力，是让程序员在类即将创建前获取其细节。例如，`__new__()` 接收类名、基类和方法数据等全部基本信息。检查这些数据可以执行各种诊断检查；更大胆的话，还可以修改数据，改变最终进入类定义的内容。不用说，这也带来了许多可怕的作恶机会。
