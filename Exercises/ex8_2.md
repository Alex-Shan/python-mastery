# 练习 8.2

*目标：*

- 使用生成器建立处理流水线

*新建文件：* `ticker.py`

**注意**

本练习要求 `stocksim.py` 继续在后台运行，并将使用上一练习编写的 `follow()`。

## (a) 建立处理流水线

生成器的重要能力之一，是让程序能够建立类似 Unix 管道的数据处理流水线。执行以下步骤，体验这一概念：

```python
>>> from follow import follow
>>> import csv
>>> lines = follow('Data/stocklog.csv')
>>> rows = csv.reader(lines)
>>> for row in rows:
        print(row)

['BA', '98.35', '6/11/2007', '09:41.07', '0.16', '98.25', '98.35', '98.31', '158148']
['AA', '39.63', '6/11/2007', '09:41.07', '-0.03', '39.67', '39.63', '39.31', '270224']
['XOM', '82.45', '6/11/2007', '09:41.07', '-0.23', '82.68', '82.64', '82.41', '748062']
['PG', '62.95', '6/11/2007', '09:41.08', '-0.12', '62.80', '62.97', '62.61', '454327']
...
```

很有意思：`follow()` 的输出被送入 `csv.reader()`，现在得到的是拆分后的数据行序列。

## (b) 创建更多流水线组件

在 `ticker.py` 中定义以下类，使用之前的结构代码，并建立流水线：

```python
# ticker.py

from structure import Structure

class Ticker(Structure):
    name = String()
    price = Float()
    date = String()
    time = String()
    change = Float()
    open = Float()
    high = Float()
    low = Float()
    volume = Integer()

if __name__ == '__main__':
    from follow import follow
    import csv
    lines = follow('Data/stocklog.csv')
    rows = csv.reader(lines)
    records = (Ticker.from_row(row) for row in rows)
    for record in records:
        print(record)
```

运行时，应看到类似以下输出：

    Ticker('IBM',103.53,'6/11/2007','09:53.59',0.46,102.87,103.53,102.77,541633)
    Ticker('MSFT',30.21,'6/11/2007','09:54.01',0.16,30.05,30.21,29.95,7562516)
    Ticker('AA',40.01,'6/11/2007','09:54.01',0.35,39.67,40.15,39.31,576619)
    Ticker('T',40.1,'6/11/2007','09:54.08',-0.16,40.2,40.19,39.87,1312959)

## (c) 继续推进

还可以做得更好。将它接入表格生成代码，把程序修改为：

```python
# ticker.py
...

if __name__ == '__main__':
    from follow import follow
    import csv
    from tableformat import create_formatter, print_table

    formatter = create_formatter('text')

    lines = follow('Data/stocklog.csv')
    rows = csv.reader(lines)
    records = (Ticker.from_row(row) for row in rows)
    negative = (rec for rec in records if rec.change < 0)
    print_table(negative, ['name','price','change'], formatter)
```

**讨论**

由此可见，可以创建各种生成器函数并串联起来，构成数据流处理流水线。

可以把生成器函数想象成乐高积木：先构建一组小型迭代模式，再以不同方式组合。这是一种很强大的编程方式。
