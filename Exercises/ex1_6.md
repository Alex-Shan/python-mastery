## (a) 使用 import 语句

前面的练习编写了 `pcost.py` 和 `stock.py` 两个程序。使用 `import` 语句加载它们并使用其功能：

```python
>>> import pcost
44671.15
>>> pcost.portfolio_cost('Data/portfolio2.dat')
19908.75
>>> from stock import Stock
>>> s = Stock('GOOG', 100, 490.10)
>>> s.name
'GOOG'
>>> s.cost()
49010.0
>>>
```

如果以上语句无法正常工作，可能是程序放在了不合适的目录。确保运行 Python 时所在目录与这些文件相同，或者文件所在目录已包含在 `sys.path` 中。
