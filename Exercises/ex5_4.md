# 练习 5.4

*目标：*

- 深入了解闭包

本节简要探索闭包（closure）的几个不太常见的方面。

## (a) 将闭包用作数据结构

闭包可用于数据封装。试试以下例子：

```python
def counter(value):
    def incr():
        nonlocal value
        value += 1
        return value

    def decr():
        nonlocal value
        value -= 1
        return value

    return incr, decr
```

此代码定义了两个操作某个值的内部函数。试试看：

```python
>>> up, down = counter(0)
>>> up()
1
>>> up()
2
>>> up()
3
>>> down()
2
>>> down()
1
>>>
```

这里既没有类定义，也没有全局变量，但 `up()` 和 `down()` 却在操作一个“幕后的”值，相当神奇。

## (b) 将闭包用作代码生成器

[练习 4.3](ex4_3.md) 开发了一组描述符类，为对象属性提供类型检查。例如：

```python

class Stock:
    name = String()
    shares = Integer()
    price = Float()
```

也可以通过闭包实现。创建 ``typedproperty.py``，写入以下代码：

```python
# typedproperty.py

def typedproperty(name, expected_type):
    private_name = '_' + name

    @property
    def value(self):
        return getattr(self, private_name)

    @value.setter
    def value(self, val):
        if not isinstance(val, expected_type):
            raise TypeError(f'Expected {expected_type}')
        setattr(self, private_name, val)
   
    return value
```

看似奇特，但这个函数实际上是在生成代码。在类定义中可以这样使用：

```python
from typedproperty import typedproperty

class Stock:
    name = typedproperty('name', str)
    shares = typedproperty('shares', int)
    price = typedproperty('price', float)

    def __init__(self, name, shares, price):
        self.name = name
        self.shares = shares
        self.price = price
```

验证该类与描述符代码一样执行类型检查。

在 `typedproperty.py` 中添加 `String()`、`Integer()` 和 `Float()`，使其支持以下代码：

```python
from typedproperty import String, Integer, Float

class Stock:
    name = String('name')
    shares = Integer('shares')
    price = Float('price')
    def __init__(self, name, shares, price):
        self.name = name
        self.shares = shares
        self.price = price
```

## (c) 挑战：省略名称

修改 `typedproperty.py`，使其不再要求属性名称：

```python
from typedproperty import String, Integer, Float

class Stock:
    name = String()
    shares = Integer()
    price = Float()
    def __init__(self, name, shares, price):
        self.name = name
        self.shares = shares
        self.price = price
```

提示：回想描述符的 `__set_name__()`，当描述符放入类定义时，该方法会被调用。
