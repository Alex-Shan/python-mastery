# 练习 3.4

*目标：*

- 学习如何使用私有属性、特性和槽封装对象内部实现

*修改文件：* `stock.py`

## (a) 私有属性

通常，类内部使用的属性应以下划线开头。上一练习的 `Stock` 类用 `types` 类变量转换数据行。修改代码，为此变量添加前导下划线。

## (b) 用特性实现计算属性

之前定义了 `Stock` 类。例如：

```python
>>> s = Stock('GOOG',100,490.10)
>>> s.name
'GOOG'
>>> s.shares
100
>>> s.price
490.1
>>> s.cost()
49010.0
>>>
```

使用特性（property）将 `cost()` 转为无需括号即可访问的属性。例如：

```python
>>> s = Stock('GOOG', 100, 490.1)
>>> s.cost               # Property. Computes the cost
49010.0
>>> 
```

## (c) 强制执行验证规则

使用特性和私有属性修改 `Stock` 的 `shares`，使其只能被赋予非负整数；同样修改 `price`，使其只能被赋予非负浮点数。

除额外的类型和值检查外，新对象的行为应与旧对象几乎完全相同。

```python
>>> s = Stock('GOOG', 100, 490.10)
>>> s.shares = 50          # OK
>>> s.shares = '50'
Traceback (most recent call last):
...
TypeError: Expected integer
>>> s.shares = -10
Traceback (most recent call last):
...
ValueError: shares must be >= 0

>>> s.price = 123.45       # OK
>>> s.price = '123.45'
Traceback (most recent call last):
...
TypeError: Expected float
>>> s.price = -10.0
Traceback (most recent call last):
...
ValueError: price must be >= 0
>>>
```

## (d) 添加 `__slots__`

修改新的 `Stock` 类，使用 `__slots__`。需要列出与之前不同的属性名，具体而言是私有属性名。例如，若特性将值存入 `_shares`，就应在 `__slots__` 中列出 `_shares`。验证类仍可正常工作，且无法再添加新属性。

```python
>>> s = Stock('GOOG', 100, 490.10)
>>> s.spam = 42
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
AttributeError: 'Stock' object has no attribute 'spam'
>>>
```

## (e) 统一类型定义

当前 `Stock` 中，`_types` 指定文件读取时的类型转换，特性又在强制检查类型，到底谁说了算？修改特性，使其采用 `_types` 指定的类型。确保通过子类改变类型时，特性仍能正常工作。例如：

```python
>>> from decimal import Decimal
>>> class DStock(Stock):
        _types = (str, int, Decimal)

>>> s = DStock('AA', 50, Decimal('91.1'))
>>> s.price = 92.3
Traceback (most recent call last):
...
TypeError: Expected a Decimal
>>> 
```
