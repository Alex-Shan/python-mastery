# 练习 7.4

*目标：*

- 了解创建类涉及的底层步骤

*修改文件：* `validate.py`, `structure.py`

本练习探索类实际创建过程的机制。

## (a) 创建类

回顾之前练习中的简单 `Stock`：

```python
class Stock:
    def __init__(self,name,shares,price):
        self.name = name
        self.shares = shares
        self.price = price
    def cost(self):
        return self.shares*self.price
    def sell(self,nshares):
        self.shares -= nshares
```

现在手动创建这个类。先将方法定义为普通 Python 函数。

```python
>>> def __init__(self,name,shares,price):
        self.name = name
        self.shares = shares
        self.price = price

>>> def cost(self):
        return self.shares*self.price

>>> def sell(self,nshares):
        self.shares -= nshares

>>>
```

接着创建方法字典：

```python
>>> methods = {
         '__init__' : __init__,
         'cost' : cost,
         'sell' : sell } 

>>>
```

最后创建 `Stock` 类对象：

```python
>>> Stock = type('Stock',(object,),methods)
>>> s = Stock('GOOG',100,490.10)
>>> s.name
'GOOG'
>>> s.cost()
49010.0
>>> s.sell(25)
>>> s.shares
75
>>>
```

恭喜，你刚创建了一个类。类实际上不过是名称、基类元组，以及保存全部类内容的字典。给 `type()` 传入这三部分，它就会作为构造器创建类。

## (b) 带类型的结构

在 `structure.py` 中定义以下函数：

```python
# structure.py

...
def typed_structure(clsname, **validators):
    cls = type(clsname, (Structure,), validators)
    return cls
```

它与 `namedtuple()` 有些类似，都会创建类。试试看：

```python
>>> from validate import String, PositiveInteger, PositiveFloat
>>> from structure import typed_structure
>>> Stock = typed_structure('Stock', name=String(), shares=PositiveInteger(), price=PositiveFloat())
>>> s = Stock('GOOG', 100, 490.1)
>>> s.name
'GOOG'
>>> s
Stock('GOOG', 100, 490.1)
>>>
```

你现在可能已经觉得脑袋快裂开了。

## (c) 创建大量类


其他一些场景下，直接使用 `type()` 构造器也很有利。考虑以下代码：

```python
# validate.py
...

class Typed(Validator):
    expected_type = object
    @classmethod
    def check(cls, value):
        if not isinstance(value, cls.expected_type):
            raise TypeError(f'expected {cls.expected_type}')
        super().check(value)

class Integer(Typed):
    expected_type = int

class Float(Typed):
    expected_type = float

class String(Typed):
    expected_type = str
...
```

最后一部分既烦人又重复。修改为使用所需类型类的表：

```python
# validate.py
...

_typed_classes = [
    ('Integer', int),
    ('Float', float),
    ('String', str) ]

globals().update((name, type(name, (Typed,), {'expected_type':ty}))
                 for name, ty in _typed_classes)
```

现在如需更多类型类，只需添加到表中：

```python
_typed_classes = [
    ('Integer', int),
    ('Float', float),
    ('Complex', complex),
    ('Decimal', decimal.Decimal),
    ('List', list),
    ('Bool', bool),
    ('String', str) ]
```

承认吧，这很酷，也能节省大量键盘输入。
