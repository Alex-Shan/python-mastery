# 练习 8.6

*目标：*

- 了解生成器委托

*修改文件：* `cofollow.py`, `server.py`

基于生成器的代码在编写库和向用户隐藏细节时可能遇到问题。驱动整个系统通常需要许多底层机制，直接暴露给用户往往很别扭。

从 Python 3.3 开始，新增的 `yield from` 可将生成器委托给另一个函数，是整理生成器代码的实用方式。

## (a) 示例：接收消息

[练习 8.3](ex8_3.md) 介绍了协程：可以向其发送数据的函数。例如：

```python
>>> from cofollow import consumer
>>> @consumer
    def printer():
        while True:
            item = yield
            print('Got:', item)

>>> p = printer()
>>> p.send('Hello')
Got: Hello
>>> p.send('World')
Got: World
>>>
```

当时用 `yield` 接收值可能很有趣，但仔细看代码，一个单独的 `yield` 显得很奇怪，到底在做什么？

在 `cofollow.py` 中定义以下函数：

```python
def receive(expected_type):
    msg = yield
    assert isinstance(msg, expected_type), 'Expected type %s' % (expected_type)
    return msg
```

它接收消息，然后验证类型是否符合预期。试试看：

```python
>>> from cofollow import consumer, receive
>>> @consumer
    def print_ints():
        while True:
             val = yield from receive(int)
             print('Got:', val)

>>> p = print_ints()
>>> p.send(42)
Got: 42
>>> p.send(13)
Got: 13
>>> p.send('13')
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
  ...
AssertionError: Expected type <class 'int'>
>>> 
```

从可读性看，`yield from receive(int)` 更能说明意图：函数将让出执行权，直到收到指定类型的消息。

修改 `coticker.py` 的全部协程，使用新的 `receive()`，并确认[练习 8.3](ex8_3.md) 的代码仍可正常工作。

## (b) 包装套接字

上一练习用生成器编写了简单的网络回显服务器，代码如下：

```python
def tcp_server(address, handler):
    sock = socket(AF_INET, SOCK_STREAM)
    sock.setsockopt(SOL_SOCKET, SO_REUSEADDR, 1)
    sock.bind(address)
    sock.listen(5)
    while True:
        yield 'recv', sock
        client, addr = sock.accept()
        tasks.append(handler(client, addr))
        
def echo_handler(client, address):
    print('Connection from', address)
    while True:
        yield 'recv', client
        data = client.recv(1000)
        if not data:
            break
        yield 'send', client
        client.send(b'GOT:', data)
    print('Connection closed')
```

创建 `GenSocket` 类，整理 `yield` 语句，使服务器可以简化为：

```python
def tcp_server(address, handler):
    sock = GenSocket(socket(AF_INET, SOCK_STREAM))
    sock.setsockopt(SOL_SOCKET, SO_REUSEADDR, 1)
    sock.bind(address)
    sock.listen(5)
    while True:
        client, addr = yield from sock.accept()
        tasks.append(handler(client, addr))
        
def echo_handler(client, address):
    print('Connection from', address)
    while True:
        data = yield from client.recv(1000)
        if not data:
            break
        yield from client.send(b'GOT:', data)
    print('Connection closed')
```

## (c) Async/Await

为刚编写的 `GenSocket` 中所有使用 `yield` 的方法添加 `types` 模块的 `@coroutine` 装饰器。

```python
from types import coroutine
...

class GenSocket:
    def __init__(self, sock):
        self.sock = sock

    @coroutine
    def accept(self):
        yield 'recv', self.sock
        client, addr = self.sock.accept()
        return GenSocket(client), addr

    @coroutine
    def recv(self, maxsize):
        yield 'recv', self.sock
        return self.sock.recv(maxsize)

    @coroutine
    def send(self, data):
        yield 'send', self.sock
        return self.sock.send(data)

    def __getattr__(self, name):
        return getattr(self.sock, name)
```

再用 `async` 函数和 `await` 语句重写服务器：

```python
async def tcp_server(address, handler):
    sock = GenSocket(socket(AF_INET, SOCK_STREAM))
    sock.setsockopt(SOL_SOCKET, SO_REUSEADDR, 1)
    sock.bind(address)
    sock.listen(5)
    while True:
        client, addr = await sock.accept()
        tasks.append(handler(client, addr))
        
async def echo_handler(client, address):
    print('Connection from', address)
    while True:
        data = await client.recv(1000)
        if not data:
            break
        await client.send(b'GOT:', data)
    print('Connection closed')
```
