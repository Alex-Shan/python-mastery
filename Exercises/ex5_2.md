# 练习 5.2

*目标：*

- 从函数返回值

本练习简要讨论函数返回值相关问题。乍看很简单，却存在一些细微问题。

## (a) 返回多个值

假设正在编写代码，解析由如下文本行组成的配置文件：

    name=value

编写 `parse_line(line)`，接收这样的行，同时返回相应的名称和值。返回多个值的常见约定是将其放入元组。例如：

```python
>>> parse_line('email=guido@python.org')
('email', 'guido@python.org')
>>> name, val = parse_line('email=guido@python.org')
>>> name
'email'
>>> val
'guido@python.org'
>>>
```

## (b) 返回可选值

函数有时返回可选值，例如用于表示成功或失败。最常见的约定是用 `None` 表示缺失值。修改上面的 `parse_line()`，使其成功时返回元组，遇到错误数据时返回 `None`。例如：

```python
>>> parse_line('email=guido@python.org')
('email', 'guido@python.org')
>>> parse_line('spam')       # Returns None
>>>
```

设计讨论：遇到格式错误的数据时，`parse_line()` 抛出异常是否更好？

## (c) Future 对象

Python 代码有时通过线程或进程并发执行。试试以下示例：

```python
>>> import time
>>> def worker(x, y):
        print('About to work')
        time.sleep(20)
        print('Done')
        return x + y

>>> worker(2, 3)     # Normal function call
About to work  
Done
5
>>>
```

现在，在独立线程中启动 `worker()`：

```python
>>> import threading
>>> t = threading.Thread(target=worker, args=(2, 3))
>>> t.start()
About to work
>>>
Done
```

注意，计算结果没有出现在任何地方，而且你甚至不知道何时完成。这存在协调问题。通常会将函数结果包装到 `Future` 中；`Future` 表示未来的结果。用法如下：

```python
>>> from concurrent.futures import Future
>>> # Wrapper around the function to use a future
>>> def do_work(x, y, fut):
        fut.set_result(worker(x,y))

>>> fut = Future()
>>> t = threading.Thread(target=do_work, args=(2, 3, fut))
>>> t.start()
About to work  
>>> result = fut.result()
Done
>>> result
5
>>>
```

使用线程池、进程等机制时，经常会看到这种模式。例如：

```python
>>> from concurrent.futures import ThreadPoolExecutor
>>> pool = ThreadPoolExecutor()
>>> fut = pool.submit(worker, 2, 3)
About to work
>>> fut
<Future at 0x102157080 state=running>
>>> fut.result()
Done
5
>>>
```
