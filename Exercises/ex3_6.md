## (a) 改善对象的输出表示

所有 Python 对象都有两种字符串表示。第一种通过 `str()` 转换得到（`print` 会调用它），通常是供人阅读的美观格式。第二种是由 `repr()` 创建的代码表示，也是在交互式 shell 中直接查看值时看到的表示，通常展示创建该对象所需输入的代码。以下用日期说明：

```python
>>> from datetime import date
>>> d = date(2008, 7, 5)
>>> print(d)              # uses str()
2008-07-05
>>> d    # uses repr()
datetime.date(2008, 7, 5)
>>>
```

有几种方式可以在输出中获得 `repr()` 字符串：

```python
>>> print('The date is', repr(d))
The date is datetime.date(2008, 7, 5)
>>> print(f'The date is {d!r}')
The date is datetime.date(2008, 7, 5)
>>> print('The date is %r' % d)
The date is datetime.date(2008, 7, 5)
>>> 
```

修改之前创建的 `Stock`，让 `__repr__()` 产生更有用的输出。例如：

```python
>>> goog = Stock('GOOG', 100, 490.10)
>>> goog
Stock('GOOG', 100, 490.1)
>>>
```

## (b) 使对象可比较

创建两个相同的 `Stock` 对象并比较，会怎样？试试看：

```python
>>> a = Stock('GOOG', 100, 490.1)
>>> b = Stock('GOOG', 100, 490.1)
>>> a == b
False
>>>
```

给 `Stock` 添加 `__eq__()` 即可解决。例如：

```python
class Stock:
    ...
    def __eq__(self, other):
        return isinstance(other, Stock) and ((self.name, self.shares, self.price) == 
                                             (other.name, other.shares, other.price))
    ...
```

## (c) 上下文管理器

[练习 3.5](ex3_5.md) 允许用户创建美观的表格。例如：

```python
>>> from tableformat import create_formatter
>>> formatter = create_formatter('text')
>>> print_table(portfolio, ['name','shares','price'], formatter)
      name     shares      price
---------- ---------- ---------- 
        AA        100       32.2
       IBM         50       91.1
       CAT        150      83.44
      MSFT        200      51.23
        GE         95      40.37
      MSFT         50       65.1
       IBM        100      70.44
>>>
```

问题在于所有表格均输出到标准输出（`sys.stdout`）。如果想重定向到文件或其他位置，可以全面修改表格格式化代码，支持不同输出文件。不过，临时需要时，也可以用上下文管理器（context manager）解决。

定义以下上下文管理器：

```python
>>> import sys
>>> class redirect_stdout:
        def __init__(self, out_file):
            self.out_file = out_file
        def __enter__(self):
            self.stdout = sys.stdout
            sys.stdout = self.out_file
            return self.out_file
        def __exit__(self, ty, val, tb):
            sys.stdout = self.stdout
```

它临时替换 `sys.stdout`，将所有输出重定向到另一个文件；退出时恢复原值。试试看：

```python
>>> from tableformat import create_formatter
>>> formatter = create_formatter('text')
>>> with redirect_stdout(open('out.txt', 'w')) as file:
        tableformat.print_table(portfolio, ['name','shares','price'], formatter)
        file.close()

>>> # Inspect the file
>>> print(open('out.txt').read())
      name     shares      price
---------- ---------- ---------- 
        AA        100       32.2
       IBM         50       91.1
       CAT        150      83.44
      MSFT        200      51.23
        GE         95      40.37
      MSFT         50       65.1
       IBM        100      70.44
>>>
```
