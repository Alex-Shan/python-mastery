## 第 1 部分：数值

Python 中的数值计算基本符合直觉。例如：

```python
>>> 3 + 4*5
23
>>> 23.45 / 1e-02
2345.0
>>>
```

注意，Python 2 和 Python 3 的整数除法不同。

```python
>>> 7 / 4      # In python 2, this truncates to 1
1.75           
>>> 7 // 4     # Truncating division
1 
>>> 
```

要在 Python 2 中获得 Python 3 的行为，可以这样做：

```python
>>> from __future__ import division
>>> 7 / 4
1.75
>>> 7 // 4      # Truncating division
1
>>>
```

数值提供少量方法，其中许多是较新加入的，连经验丰富的 Python 程序员也容易忽略。试用其中一些方法。

```python
>>> x = 1172.5
>>> x.as_integer_ratio()
(2345, 2)
>>> x.is_integer()
False
>>> y = 12345
>>> y.numerator
12345
>>> y.denominator
1
>>> y.bit_length()
14
>>> 
```

## 第 2 部分：字符串操作

定义一个包含一系列股票代码的字符串：

```python
>>> symbols = 'AAPL IBM MSFT YHOO SCO'
```

现在来试试不同的字符串操作：

### (a) 提取单个字符和子串

字符串是字符数组。尝试提取几个字符：

```python
>>> symbols[0]
'A'
>>> symbols[1]
'A'
>>> symbols[2]
'P'
>>> symbols[-1]        # Last character
'O'
>>> symbols[-2]        # 2nd from last character
'C'
>>>
```

尝试获取几个切片：

```python
>>> symbols[:4]
'AAPL'
>>> symbols[-3:]
'SCO'
>>> symbols[5:8]
'IBM'
>>>
```

### (b) 字符串是只读对象

字符串是只读的。尝试将 `symbols` 的第一个字符改为小写的 'a' 来验证这一点。

```python
>>> symbols[0] = 'a'
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: 'str' object does not support item assignment
>>> 
```

### (c) 字符串拼接

虽然字符串数据是只读的，但可以随时将变量重新绑定到新创建的字符串。尝试以下语句，将新的股票代码 "GOOG" 拼接到 `symbols` 末尾：

```python
>>> symbols += ' GOOG'             
>>> symbols
... look at the result ...
```

再尝试将 "HPQ" 添加到 `symbols` 开头：

```python
>>> symbols = 'HPQ ' + symbols     
>>> symbols
... look at the result ...
```

注意，在这两个例子中，原字符串 `symbols` 都_没有_被“就地”修改。实际上创建了一个全新的字符串，变量名 `symbols` 只是绑定到了结果上。此后，旧字符串不再被使用，因此会被销毁。


### (d) 成员测试（子串测试）

使用 `in` 运算符检查子串。在交互式提示符下试试这些操作：

```python
>>> 'IBM' in symbols
True
>>> 'AA' in symbols
True
>>> 'CAT' in symbols
False
>>>
```

确保理解为什么检查 "AA" 会返回 `True`。

### (e) 字符串方法

在 Python 交互式提示符下试用一些字符串方法。

```python
>>> symbols.lower()
'hpq aapl ibm msft yhoo sco goog'
>>> symbols       
'HPQ AAPL IBM MSFT YHOO SCO GOOG'
```

记住，字符串始终是只读的。如果要保存某次操作的结果，就需要将它赋给变量：

```python
>>> lowersyms = symbols.lower()
>>> lowersyms
'hpq aapl ibm msft yhoo sco goog'
>>>
```

再试试其他操作：

```python
>>> symbols.find('MSFT')
13
>>> symbols[13:17]
'MSFT'
>>> symbols = symbols.replace('SCO','')
>>> symbols
'HPQ AAPL IBM MSFT YHOO  GOOG'
>>>
```

## 第 3 部分：列表操作

第一部分使用了包含股票代码的字符串。例如：

```python
>>> symbols = 'HPQ AAPL IBM MSFT YHOO  GOOG'
>>>
```

定义上述变量，用字符串的 `split()` 操作将其拆分成名称列表：

```python
>>> symlist = symbols.split()
>>> symlist
['HPQ', 'AAPL', 'IBM', 'MSFT', 'YHOO', 'GOOG' ]
>>>
```

### (a) 提取列表元素并重新赋值

列表类似数组，可以通过数字索引查找和修改元素。尝试几次查找：

```python
>>> symlist[0]
'HPQ'
>>> symlist[1]
'AAPL'
>>> symlist[-1]
'GOOG'
>>> symlist[-2]
'YHOO'
>>>
```

尝试给其中一项重新赋值：

```python
>>> symlist[2] = 'AIG'
>>> symlist
['HPQ', 'AAPL', 'AIG', 'MSFT', 'YHOO', 'GOOG' ]
>>>
```

### (b) 遍历列表元素

`for` 循环会遍历列表等序列中的数据。输入以下循环，观察结果：

```python
>>> for s in symlist:
        print('s =', s)

... look at the output ...
```

### (c) 成员测试

使用 `in` 运算符检查 `'AIG'`、`'AA'` 和 `'CAT'` 是否在股票代码列表中。

```python
>>> 'AIG' in symlist
True
>>> 'AA' in symlist
False
>>>
```

### (d) 追加、插入和删除元素

使用 `append()` 方法将股票代码 `'RHT'` 添加到 `symlist` 末尾。

```python
>>> symlist.append('RHT')
>>> symlist
['HPQ', 'AAPL', 'AIG', 'MSFT', 'YHOO', 'GOOG', 'RHT']
>>> 
```

使用 `insert()` 方法将股票代码 `'AA'` 插入为列表的第二项。

```python
>>> symlist.insert(1,'AA')
>>> symlist
['HPQ', 'AA', 'AAPL', 'AIG', 'MSFT', 'YHOO', 'GOOG', 'RHT']
>>>
```

使用 `remove()` 方法从列表中删除 `'MSFT'`。

```python
>>> symlist.remove('MSFT')
>>> symlist
['HPQ', 'AA', 'AAPL', 'AIG', 'YHOO', 'GOOG', 'RHT']
```

再次调用 `remove()`，看看找不到元素时会发生什么。

```python
>>> symlist.remove('MSFT')
... watch what happens ...
>>>
```

使用 `index()` 方法查找 `'YHOO'` 在列表中的位置。

```python
>>> symlist.index('YHOO')
4
>>> symlist[4]
'YHOO'
>>>
```

### (e) 列表排序

想给列表排序？使用 `sort()` 方法，试试看：

```python
>>> symlist.sort()
>>> symlist
['AA', 'AAPL', 'AIG', 'GOOG', 'HPQ', 'RHT', 'YHOO']
>>>
```

想按相反顺序排序？试试这个：

```python
>>> symlist.sort(reverse=True)
>>> symlist
['YHOO', 'RHT', 'HPQ', 'GOOG', 'AIG', 'AAPL', 'AA']
>>>
```

注意：排序会“就地”修改列表内容，也就是重新排列列表中的元素，而不创建新列表。


### (f) 包含任意对象的列表

列表可以包含任意类型的对象，包括其他列表（即嵌套列表）。试试看：

```python
>>> nums = [101,102,103]
>>> items = [symlist, nums]
>>> items
[['YHOO', 'RHT', 'HPQ', 'GOOG', 'AIG', 'AAPL', 'AA'], [101, 102, 103]]
```

仔细观察以上输出。`items` 是一个含有两个元素的列表，每个元素又是一个列表。

尝试几次嵌套列表查找：

```python
>>> items[0]
['YHOO', 'RHT', 'HPQ', 'GOOG', 'AIG', 'AAPL', 'AA']
>>> items[0][1]
'RHT'
>>> items[0][1][2]
'T'
>>> items[1]
[101, 102, 103]
>>> items[1][1]
102
>>>
```

## 第 4 部分：字典

前面几部分只处理了股票代码。如果想把股票代码映射到价格等其他数据，该怎么办？可以使用字典：

```python
>>> prices = { 'IBM': 91.1, 'GOOG': 490.1, 'AAPL':312.23 }
>>>
```

字典将键映射到值。访问方式如下：

```python
>>> prices['IBM']
91.1
>>> prices['IBM'] = 123.45
>>> prices['HPQ'] = 26.15
>>> prices
{'GOOG': 490.1, 'AAPL': 312.23, 'IBM': 123.45, 'HPQ': 26.15}
>>>
```

要获取键的列表，可以这样做：

```python
>>> list(prices)
['GOOG', 'AAPL', 'IBM', 'HPQ']
>>>
```

要删除一个值，使用 `del`：

```python
>>> del prices['AAPL']
>>> prices
{'GOOG': 490.1, 'IBM': 123.45, 'HPQ': 26.15}
>>>
```
