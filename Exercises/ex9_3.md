# 练习 9.3

*目标：*

- 学习控制导出符号和整合子模块
- 学习拆分模块

包有个可能令人烦恼的方面：它让导入语句更复杂。例如，`stock.py` 现在有如下导入：

```python
from structly.structure import Structure
from structly.reader import read_csv_as_instances
from structly.tableformat import create_formatter, print_table
```

如果包是作为统一整体使用的，将所有内容整合到顶层包可能更合理，也更简单。开始吧：

## (a) 控制导出符号

修改 `structly` 的所有子模块，显式定义 `__all__`，导出选定符号。具体要求：

- `structure.py` 导出 `Structure`。
- `reader.py` 导出各个 `read_csv_as_*()` 函数。
- `tableformat.py` 导出 `create_formatter()` 和 `print_table()`。

然后在 `__init__.py` 中整合所有子模块：

```python
# structly/__init__.py

from .structure import *
from .reader import *
from .tableformat import *
```

完成后，可以从单一逻辑模块导入所有内容：

```python
# stock.py

from structly import Structure

class Stock(Structure):
    name = String()
    shares = PositiveInteger()
    price = PositiveFloat()
    
    @property
    def cost(self):
        return self.shares * self.price

    def sell(self, nshares: PositiveInteger):
        self.shares -= nshares

if __name__ == '__main__':
    from structly import read_csv_as_instances, create_formatter, print_table
    portfolio = read_csv_as_instances('Data/portfolio.csv', Stock)
    formatter = create_formatter('text')
    print_table(portfolio, ['name','shares','price'], formatter)
```

## (b) 导出所有内容

在 `structly/__init__.py` 定义包含所有导出符号的 `__all__`，然后进一步简化 `stock.py`：

```python
# stock.py

from structly import *

class Stock(Structure):
    name = String()
    shares = PositiveInteger()
    price = PositiveFloat()
    
    @property
    def cost(self):
        return self.shares * self.price

    def sell(self, nshares: PositiveInteger):
        self.shares -= nshares

if __name__ == '__main__':
    portfolio = read_csv_as_instances('Data/portfolio.csv', Stock)
    formatter = create_formatter('text')
    print_table(portfolio, ['name','shares','price'], formatter)
```

顺便说一句，Python 社区通常不赞成 `from module import *`，尤其是使用者不清楚其含义时。不过，有些情况下它确实合理，例如包定义了大量常用符号或常量时。


## (c) 拆分模块

`structly/tableformat.py` 包含创建不同格式表格的代码，具体有：

- `TableFormatter` 基类。
- `TextTableFormatter` 类。
- `CSVTableFormatter` 类。
- `HTMLTableFormatter` 类。

与其把所有类放在一个 `.py` 文件中，也许将每个具体格式化器移入独立文件更合理。接下来拆分 `tableformat.py`，请仔细按照步骤操作：

首先，删除 `structly/__pycache__`。

```
% cd structly
% rm -rf __pycache__
```

然后创建 `structly/tableformat` 目录，名称必须与被替代的模块 `tableformat.py` 相同。

```
bash % mkdir tableformat
bash %
```

将原来的 `tableformat.py` 移入新 `tableformat` 目录，并重命名为 `formatter.py`。

```
bash % mv tableformat.py tableformat/formatter.py
bash %
```

在 `tableformat` 中，将 `tableformat.py` 的代码拆分为以下文件和目录：

- `formatter.py`：包含 `TableFormatter` 基类、混入类和各个函数。
- `formats/text.py`：包含 `TextTableFormatter`。
- `formats/csv.py`：包含 `CSVTableFormatter`。
- `formats/html.py`：包含 `HTMLTableFormatter`。

在 `tableformat/` 和 `tableformat/formats` 中添加 `__init__.py`。让 `tableformat/__init__.py` 导出与原 `tableformat.py` 相同的符号。

完成后，包结构应如下：

```
structly/
      __init__.py
      validate.py
      reader.py
      structure.py
      tableformat/
           __init__.py
           formatter.py
           formats/
               __init__.py
               text.py
               csv.py
               html.py
```

对用户而言，所有功能应与之前完全一致。例如，之前的 `stock.py` 应能正常工作：

```python
# stock.py

from structly import *

class Stock(Structure):
    name = String()
    shares = PositiveInteger()
    price = PositiveFloat()
    
    @property
    def cost(self):
        return self.shares * self.price

    def sell(self, nshares):
        self.shares -= nshares

    portfolio = read_csv_as_instances('Data/portfolio.csv', Stock)
    formatter = create_formatter('text')
    print_table(portfolio, ['name','shares','price'], formatter)
```
