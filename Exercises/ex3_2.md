*目标：*

*新建文件：* `tableformat.py`

## (a) 三种操作

整个 Python 对象系统只有三种核心操作：获取、设置和删除属性。通常用点号（.）访问它们：

```python
>>> s = Stock('GOOG', 100, 490.1)
>>> s.name    #  get
'GOOG'
>>> s.shares = 50    # set
>>> del s.shares     # delete
>>>
```

这三种操作也提供函数形式。例如：

```python
>>> getattr(s, 'name')            # Same as s.name
'GOOG'
>>> setattr(s, 'shares', 50)      # Same as s.shares = 50
>>> delattr(s, 'shares')          # Same as del s.shares
>>>
```

还可以使用 `hasattr()` 检查对象是否存在某个属性：

```python
>>> hasattr(s, 'name')
True
>>> hasattr(s, 'blah')
False
>>>
```

## (b) 使用 getattr()

`getattr()` 非常适合编写以通用方式处理对象的代码。例如，以下代码输出一组由用户指定的属性：

```python
>>> s= Stock('GOOG', 100, 490.1)
>>> fields = ['name','shares','price']
>>> for name in fields:
           print(name, getattr(s, name))

name GOOG
shares 100
price 490.1
>>>
```

## (c) 表格输出

[练习 3.1](ex3_1.md) 的 `print_portfolio()` 函数生成了美观的表格，但它专门针对 `Stock` 对象列表。使用 (b) 部分的技巧，可以将其完全通用化，处理任意对象列表。

创建 `tableformat.py` 模块，在其中编写 `print_table()`。它接收对象序列（列表）和属性名列表，并输出格式美观的表格。例如：

```python
>>> import stock
>>> import tableformat
>>> portfolio = stock.read_portfolio('Data/portfolio.csv')
>>> tableformat.print_table(portfolio, ['name','shares','price'])
      name     shares      price
---------- ---------- ---------- 
        AA        100       32.2
       IBM         50       91.1
       CAT        150      83.44
      MSFT        200      51.23
        GE         95      40.37
      MSFT         50       65.1
       IBM        100      70.44

>>> tableformat.print_table(portfolio,['shares','name'])
    shares       name
---------- ---------- 
       100         AA
        50        IBM
       150        CAT
       200       MSFT
        95         GE
        50       MSFT
       100        IBM
>>> 
```

为简便起见，让 `print_table()` 将每个字段输出到宽度为 10 个字符的列中即可。

## (d) 绑定方法

可能有些意外：方法调用构建在普通属性的机制之上。本质上，方法是一种属性，加上括号 () 后便可像函数一样调用。例如：

```python
>>> s = Stock('GOOG',100,490.10)
>>> s.cost           # Looks up the method
<bound method Stock.cost of <__main__.Stock object at 0x409530>>
>>> s.cost()         # Looks up and calls the method
49010.0

>>> # Same operations using getattr()
>>> getattr(s, 'cost')
<bound method Stock.cost of <__main__.Stock object at 0x409530>>
>>> getattr(s, 'cost')()
49010.0
>>> 
```

绑定方法（bound method）关联着它所属的对象。如果对象被修改，方法会看到这些修改。查看方法的 `__self__` 属性即可获取原始对象。

```python
>>> c = s.cost
>>> c()
49010.0
>>> s.shares = 75
>>> c()
36757.5
>>> c.__self__
<__main__.Stock object at 0x409530>
>>> c.__func__
<function cost at 0x37cc30>
>>> c.__func__(c.__self__)      # This is what happens behind the scenes of calling c()
36757.5
>>>
```

再用 `sell()` 方法试一试，确保理解这一机制：

```python
>>> f = s.sell
>>> f.__func__(f.__self__, 25)     # Same as s.sell(25)
>>> s.shares
50
>>>
```
