# 练习 1.4

*目标：*

- 复习简单函数的定义
- 异常处理

*新建文件：* 无

*修改文件：* `pcost.py`

## (a) 定义函数

将上一练习编写的 `pcost.py` 程序转换为函数 `portfolio_cost(filename)`。该函数以文件名为输入，读取文件中的投资组合数据，以浮点数返回总成本。写好函数后，在程序末尾加入以下语句调用它：

```python
print(portfolio_cost('Data/portfolio.dat'))
```

运行程序，确认输出与之前相同。


## (b) 添加错误处理

编写数据处理程序时，经常遇到错误数据造成的问题，例如格式不正确、字段缺失等。修改 `pcost.py`，让它读取 `Data/portfolio3.dat`，然后运行（提示：它应该崩溃）。

稍微修改函数，使其遇到错误数据行后能够继续运行。例如，`int()` 和 `float()` 无法转换输入时会抛出 `ValueError` 异常。使用 `try` 和 `except` 捕获异常，并针对无法解析的行输出警告。例如：

```
Couldn't parse: 'C - 53.08\n'
Reason: invalid literal for int() with base 10: '-'
Couldn't parse: 'DIS - 34.20\n'
Reason: invalid literal for int() with base 10: '-'
...
```

再次用 `Data/portfolio3.dat` 运行程序。尽管会输出警告，它应该能够成功运行。

## (c) 交互式实验

运行 `pcost.py`，然后从交互式解释器中直接调用 `portfolio_cost()` 函数。

```python
>>> portfolio_cost('Data/portfolio.dat')
44671.15
>>> portfolio_cost('Data/portfolio2.dat')
19908.75
>>>
```

注意：为此可能需要使用 `-i` 选项运行 Python。例如：

```
bash % python3 -i pcost.py
```
