# 练习 2.5

*目标：*

*新建文件：* 无

## (a) 列表增长

Python 列表针对 `append()` 做了高度优化。每次扩容时，列表会申请比实际所需更多的内存，以备后续追加数据。如果还有可用空间，`append()` 就能直接存储新元素，无需再次分配内存。

用 `sys.getsizeof()` 查看列表大小，并追加一些元素，观察这一特性。

```python
>>> import sys
>>> items = []
>>> sys.getsizeof(items)
64
>>> items.append(1)
>>> sys.getsizeof(items)
96
>>> items.append(2)
>>> sys.getsizeof(items)    # Notice how the size does not increase
96
>>> items.append(3)
>>> sys.getsizeof(items)    # It still doesn't increase here
96
>>> items.append(4)
>>> sys.getsizeof(items)    # Not yet.
96
>>> items.append(5)
>>> sys.getsizeof(items)    # Notice the size has jumped
128
>>>
```

列表按引用存储元素，因此每个元素只需要一个内存地址的空间。64 位机器上的地址通常占 8 字节；如果 Python 编译为 32 位，则可能占 4 字节，上例数值会减半。

## (b) 字典和类的增长

Python 字典（以及类）在预留内存翻倍前，最多能存储 5 个值。创建字典并逐步添加值，观察其行为：

```python
>>> row = { 'route': '22', 'date': '01/01/2001', 'daytype': 'U', 'rides': 7354 }
>>> sys.getsizeof(row)
240
>>> row['a'] = 1
>>> sys.getsizeof(row)
240
>>> row['b'] = 2
>>> sys.getsizeof(row)
368
>>> 
```

删除刚添加的元素后，内存占用会下降吗？

思考：如果需要创建大量记录，为每条记录使用字典可能并不高效，字典带来的便利可能伴随高昂开销。元组、命名元组或定义了 `__slots__` 的类可能更合适。

## (c) 改变数据方向：按列存储

换一种看待数据的方式，往往能节省大量内存。例如，用以下函数把全部公交数据按列读取，会怎样？

```python
# readrides.py

...

def read_rides_as_columns(filename):
    '''
    Read the bus ride data into 4 lists, representing columns
    '''
    routes = []
    dates = []
    daytypes = []
    numrides = []
    with open(filename) as f:
        rows = csv.reader(f)
        headings = next(rows)     # Skip headers
        for row in rows:
            routes.append(row[0])
            dates.append(row[1])
            daytypes.append(row[2])
            numrides.append(int(row[3]))
    return dict(routes=routes, dates=dates, daytypes=daytypes, numrides=numrides)
```

理论上，这个函数应当节省大量内存。尝试之前，先做分析。

数据文件有 577563 行，每行四个值。如果每行用字典存储，每个字典至少占 240 字节。

```python
>>> nrows = 577563     # Number of rows in original file
>>> nrows * 240
138615120
>>>
```

因此，仅字典本身就占 138MB，尚未计入字典中实际存储的值。

按列存储后，数据放在 4 个独立列表中。每个列表元素需要 8 字节保存指针。下面粗略估算列表所需空间：

```python
>>> nrows * 4 * 8
18482016
>>>
```

列表开销约为 18MB。因此，仅通过消除字典存储的额外信息，改为按列存储就应能节省约 120MB。

尝试用这个函数读取公交数据，查看内存占用。

```python

>>> tracemalloc.start()
>>> columns = read_rides_as_columns('Data/ctabus.csv')
>>> tracemalloc.get_traced_memory()

>>>
```

## (d) 创建自定义容器：以假乱真

按列存储节省了更多内存，却让数据变得难以使用。实际上，[练习 2.2](ex2_2.md) 的分析代码全部无法处理列式数据，因为先前的数据抽象被破坏了：代码假设数据存储在字典列表中。

如果愿意创建一个“伪装”数据的自定义容器对象，就可以解决这个问题。开始吧。

之前的分析代码假设数据存储为记录序列，每条记录用字典表示。先创建一个新的“序列”类，在类中存储 `read_rides_as_columns()` 使用的四列数据。

```python
# readrides.py

import collections
...
class RideData(collections.abc.Sequence):
    def __init__(self):
        self.routes = []      # Columns
        self.dates = []
        self.daytypes = []
        self.numrides = []
```

尝试创建 `RideData` 实例，会看到如下错误：

```python
>>> records = RideData()
Traceback (most recent call last):
...
TypeError: Can't instantiate abstract class RideData with abstract methods __getitem__, __len__
>>>
```

仔细阅读错误信息，它指出了需要实现的内容。添加 `__len__()` 和 `__getitem__()` 方法，在 `__getitem__()` 中构造字典。另外，创建 `append()` 方法，接收字典并将其拆分为 4 次独立的 `append()` 操作。

```python
# readrides.py
...

class RideData(collections.abc.Sequence):
    def __init__(self):
        # Each value is a list with all the values (a column)
        self.routes = []
        self.dates = []
        self.daytypes = []
        self.numrides = []
        
    def __len__(self):
        # All lists assumed to have the same length
        return len(self.routes)

    def __getitem__(self, index):
        return { 'route': self.routes[index],
                 'date': self.dates[index],
                 'daytype': self.daytypes[index],
                 'rides': self.numrides[index] }

    def append(self, d):
        self.routes.append(d['route'])
        self.dates.append(d['date'])
        self.daytypes.append(d['daytype'])
        self.numrides.append(d['rides'])
```

正确实现后，只需修改一行代码，就可以将此对象放入之前的 `read_rides_as_dicts()` 函数：

```python
# readrides.py
...

def read_rides_as_dicts(filename):
    '''
    Read the bus ride data as a list of dicts
    '''
    records = RideData()      # <--- CHANGE THIS
    with open(filename) as f:
        rows = csv.reader(f)
        headings = next(rows)     # Skip headers
        for row in rows:
            route = row[0]
            date = row[1]
            daytype = row[2]
            rides = int(row[3])
            record = {
                'route': route, 
                'date': date, 
                'daytype': daytype, 
                'rides' : rides
                }
            records.append(record)
    return records
```
