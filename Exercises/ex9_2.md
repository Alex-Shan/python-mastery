# 练习 9.2

*目标：*

- 学习创建 Python 包

**注意**

本练习主要是在文件系统中复制文件，编程量不大。

## (a) 创建包

之前的练习创建了以下文件，分别涉及带类型检查的结构、数据读取和表格生成：

- `structure.py`
- `validate.py`
- `reader.py`
- `tableformat.py`

任务是将所有这些文件移入名为 `structly` 的包。步骤如下：

- 创建 `structly` 目录。
- 创建空文件 `__init__.py`，放入 `structly`。
- 将 `structure.py`、`validate.py`、`reader.py` 和 `tableformat.py` 移入 `structly`。
- 修正模块之间的导入语句，尤其是依赖 `validate` 的 `structure`。

完成后，将 `stock.py` 改为与以下代码完全相同，并确保可以运行：

```python
# stock.py

from structly.structure import Structure

class Stock(Structure):
    name = String()
    shares = PositiveInteger()
    price = PositiveFloat()
    
    @property
    def cost(self):
        return self.shares * self.price

    def sell(self, nshares: PositiveInteger):
        self.shares -= nshares

if __name__ == '__main__':
    from structly.reader import read_csv_as_instances
    from structly.tableformat import create_formatter, print_table
    portfolio = read_csv_as_instances('Data/portfolio.csv', Stock)
    formatter = create_formatter('text')
    print_table(portfolio, ['name','shares','price'], formatter)
```
