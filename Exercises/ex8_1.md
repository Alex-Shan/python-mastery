## (a) 简单生成器

需要定制迭代时，应首先想到生成器函数。它很容易编写：用函数实现所需迭代逻辑，并通过 `yield` 产生值。

例如，以下生成器支持以小数为步长遍历一段数值范围，这是内置 `range()` 不支持的：

```python
>>> def frange(start,stop,step):
        while start < stop:
            yield start
            start += step

>>> for x in frange(0, 2, 0.25):
        print(x, end=' ')

0 0.25 0.5 0.75 1.0 1.25 1.5 1.75
>>>
```

生成器只能遍历一次。例如，尝试遍历两次会出现以下结果：

```python
>>> f = frange(0, 2, 0.25)
>>> for x in f:
        print(x, end=' ')

0 0.25 0.5 0.75 1.0 1.25 1.5 1.75
>>> for x in f:
        print(x, end=' ')

>>>
```

要再次遍历同一序列，需要重新调用 `frange()` 创建生成器。也可以把一切封装进类：

```python
>>> class FRange:
        def __init__(self, start, stop, step):
            self.start = start
            self.stop = stop
            self.step = step
        def __iter__(self):
            n = self.start
            while n < self.stop:
                yield n
                n += self.step

>>> f = FRange(0, 2, 0.25)
>>> for x in f:
        print(x, end=' ')

0 0.25 0.5 0.75 1.0 1.25 1.5 1.75
>>> for x in f:
        print(x, end=' ')

0 0.25 0.5 0.75 1.0 1.25 1.5 1.75
>>>
```

## (b) 为对象添加迭代功能

自定义类可以通过特殊方法 `__iter__()` 支持迭代，该方法返回迭代器。正如上一例所示，最简单的方法是将 `__iter__()` 定义为生成器。

为之前定义的 `Structure` 基类添加 `__iter__()`，按顺序产生属性值。例如：

```python
class Structure(metaclass=StructureMeta):
    ...
    def __iter__(self):
        for name in self._fields:
            yield getattr(self, name)
    ...
```

完成后，应能这样遍历实例属性：

```python
>>> from stock import Stock
>>> s = Stock('GOOG', 100, 490.1)
>>> for val in s:
        print(val)
GOOG
100
490.1
>>>
```

## (c) 迭代的惊人能力

Python 在许多意想不到的地方使用迭代。为 `Structure` 添加 `__iter__()` 后，许多新操作变得容易，例如转换为序列和解包：

```python
>>> s = Stock('GOOG', 100, 490.1)
>>> list(s)
['GOOG', 100, 490.1]
>>> tuple(s)
('GOOG', 100, 490.1)
>>> name, shares, price = s
>>> name
'GOOG'
>>> shares
100
>>> price
490.1
>>> 
```

还可以顺便为 `Structure` 添加比较运算符：

```python
# structure.py
class Structure(metaclass=StructureMeta):
    ...
    def __eq__(self, other):
        return isinstance(other, type(self)) and tuple(self) == tuple(other)
    ...
```

现在应该能比较对象：

```python
>>> a = Stock('GOOG', 100, 490.1)
>>> b = Stock('GOOG', 100, 490.1)
>>> a == b
True
>>>
```

再次运行 `teststock.py`，现在所有测试都应通过。很好。

## (d) 监控流式数据源

生成器也适合简单地产生数据流。本部分编写监视日志文件的生成器。请仔细按照以下步骤操作。

`Data/stocksim.py` 模拟股票市场数据，不断向 `stocklog.csv` 写入实时数据。在命令窗口（不是 IDLE）进入 `Data/` 并运行：

```
% python3 stocksim.py
```

Windows 用户可以找到 `stocksim.py` 并双击运行。之后暂时不用管它，让它持续在后台运行。它会运行数小时，无需担心。

程序启动后，编写一个小程序，打开文件、定位到末尾并监视新输出。创建 `follow.py`，写入以下代码：

```python
# follow.py
import os
import time
f = open('Data/stocklog.csv')
f.seek(0, os.SEEK_END)   # Move file pointer 0 bytes from end of file

while True:
    line = f.readline()
    if line == '':
        time.sleep(0.1)   # Sleep briefly and retry
        continue
    fields = line.split(',')
    name = fields[0].strip('"')
    price = float(fields[1])
    change = float(fields[4])
    if change < 0:
        print('%10s %10.2f %10.2f' % (name, price, change))
```

运行后会看到实时股票行情。它的作用类似 Unix 中用于监视日志的 `tail -f`。

**注意：** 这里使用 `readline()` 有些特别，通常读取文件行会直接使用 `for` 循环。但这里需要反复检查文件末尾是否新增数据；`readline()` 会返回新数据或空字符串。

仔细观察，代码前半部分产生数据行，`while` 末尾的语句消费数据。生成器函数的重要特点是，可以将全部数据生产代码移入可复用函数。

修改代码，由生成器函数 `follow(filename)` 完成文件读取，使以下代码可用：

```python
>>> for line in follow('Data/stocklog.csv'):
          print(line, end='')
   
... Should see lines of output produced here ...
```

将股票行情代码修改为：

```python
for line in follow('Data/stocklog.csv'):
    fields = line.split(',')
    name = fields[0].strip('"')
    price = float(fields[1])
    change = float(fields[4])
    if change < 0:
        print('%10s %10.2f %10.2f' % (name, price, change))
```

**讨论**

这里发生了一件很有力量的事：你把从文件末尾读取行的迭代模式移入独立小函数。`follow()` 成了完全通用的工具，可在任何程序中用于监视服务器日志、调试日志等类似数据源。很酷。
