# 练习 4.1

*目标：*

- 深入了解对象的表示方式
- 了解属性赋值与查找的机制
- 更好地理解类定义的作用

*新建文件：* 无

*修改文件：* None

先回到之前的简单版 `Stock` 类。在交互式提示符下定义如下 `SimpleStock`：

```python
>>> class SimpleStock:
        def __init__(self, name, shares, price):
            self.name = name
            self.shares = shares
            self.price = price
        def cost(self):
            return self.shares * self.price

>>>
```

定义后，创建几个实例。

```python
>>> goog = SimpleStock('GOOG',100,490.10)
>>> ibm  = SimpleStock('IBM',50, 91.23)
>>>
```

## (a) 实例的表示

在交互式 shell 中查看这两个实例的底层字典：

```python
>>> goog.__dict__
... look at the output ...
>>> ibm.__dict__
... look at the output ...
>>>
```

## (b) 修改实例数据

尝试为其中一个实例设置新属性：

```python
>>> goog.date = "6/11/2007"
>>> goog.__dict__
... look at output ...
>>> ibm.__dict__
... look at output ...
>>>
```

以上输出表明，`goog` 有 `date` 属性，而 `ibm` 没有。注意，Python 实际上不对属性作此类限制。例如，实例属性并不限于 `__init__()` 中设置的属性。

这次不设置属性，改为直接往 `__dict__` 对象中放入新值：

```python
>>> goog.__dict__['time'] = '9:45am'
>>> goog.time
'9:45am'
>>>
```

由此可以明显看出，实例实际上是字典之上的一层封装。


## (c) 类的作用

类定义中的内容由该类所有实例共享。注意，每个实例都有指向所属类的链接：

```python
>>> goog.__class__
... look at output ...
>>> ibm.__class__
... look at output ...
>>> 
```

尝试调用实例上的方法：

```python
>>> goog.cost()
49010.0
>>> ibm.cost()
4561.5
>>>
```

注意，`goog.__dict__` 和 `ibm.__dict__` 都没有定义 'cost'，它来自类字典。试试看：

```python
>>> SimpleStock.__dict__['cost']
... look at output ...
>>>
```

尝试直接通过字典调用 `cost()`：

```python
>>> SimpleStock.__dict__['cost'](goog)
49010.00
>>> SimpleStock.__dict__['cost'](ibm)
4561.5
>>>
```

注意，这是在调用类定义中的函数，而 `self` 参数获得了实例。

给类添加新值，它就会成为所有实例可见的类变量。试试看：

```python
>>> SimpleStock.spam = 42
>>> ibm.spam
42
>>> goog.spam
42
>>>
```

观察到 `spam` 不属于实例字典：

```python
>>> ibm.__dict__
... look at the output ...
>>>
```

它属于类字典：

```python
>>> SimpleStock.__dict__['spam']
42
>>>
```

本质上，类就是由实例共享的一组值。
