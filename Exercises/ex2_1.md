# 练习 2.1

*目标：*

- 找到存储大量数据时最节省内存的方法。
- 了解元组、字典、类和命名元组等不同的记录表示方式。

本练习从内存占用和效率出发，比较数据结构的不同表示方式。许多人用 Python 进行各类数据分析，因此了解可选方案及其取舍很有价值。

## (a) 公交数据

`Data/ctabus.csv` 是一个 CSV 文件，记录芝加哥交通管理局（CTA）公交系统从 2001 年 1 月 1 日至 2013 年 8 月 31 日的每日客流，约有 577000 行。用 Python 查看几行，了解其格式：

```python
>>> f = open('Data/ctabus.csv')
>>> next(f)
'route,date,daytype,rides\n'
>>> next(f)
'3,01/01/2001,U,7354\n'
>>> next(f)
'4,01/01/2001,U,9288\n'
>>>
```

数据共有 4 列。

- route：第 0 列，公交线路名称。
- date：第 1 列，格式为 MM/DD/YYYY 的日期字符串。
- daytype：第 2 列，日期类型代码（U=星期日/节假日，A=星期六，W=工作日）。
- rides：第 3 列，乘客总数（整数）。

`rides` 列记录某天乘坐某条线路公交车的总人数。因此，上例表示 2001 年 1 月 1 日有 7354 人乘坐 3 路公交车。

## (b) 文本的基本内存占用

先测量处理此文件所需内存的基准值。重启 Python，做一个简单实验：读取文件，将数据存入一个字符串：

```python
>>> # --- RESTART 
>>> import tracemalloc
>>> f = open('Data/ctabus.csv')
>>> tracemalloc.start()
>>> data = f.read()
>>> len(data)
12361039
>>> current, peak = tracemalloc.get_traced_memory()
>>> current
12369664
>>> peak
24730766
>>> 
```

结果可能略有不同，但当前内存占用应在 12MB 左右，峰值约为 24MB。

如果把整个文件读入字符串列表，会怎样？重启 Python，试试以下代码：

```python
>>> # --- RESTART
>>> import tracemalloc
>>> f = open('Data/ctabus.csv')
>>> tracemalloc.start()
>>> lines = f.readlines()
>>> len(lines)
577564
>>> current, peak = tracemalloc.get_traced_memory()
>>> current
45828030
>>> peak
45867371
>>> 
```

内存占用应该显著增加到 40–50MB。思考一下：额外开销可能来自哪里？

## (c) 元组列表

实际应用中，可能会将数据读入列表，并把每行转换为另一种数据结构。以下 `readrides.py` 使用 `csv` 模块将整个文件读入元组列表：

```python
# readrides.py

import csv

def read_rides_as_tuples(filename):
    '''
    Read the bus ride data as a list of tuples
    '''
    records = []
    with open(filename) as f:
        rows = csv.reader(f)
        headings = next(rows)     # Skip headers
        for row in rows:
            route = row[0]
            date = row[1]
            daytype = row[2]
            rides = int(row[3])
            record = (route, date, daytype, rides)
            records.append(record)
    return records

if __name__ == '__main__':
    import tracemalloc
    tracemalloc.start()
    rows = read_rides_as_tuples('Data/ctabus.csv')
    print('Memory Use: Current %d, Peak %d' % tracemalloc.get_traced_memory())
```

使用 `python3 -i readrides.py` 运行程序，查看 `rows` 的内容。应该得到如下元组列表：

```python
>>> len(rows)
577563
>>> rows[0]
('3', '01/01/2001', 'U', 7354)
>>> rows[1]
('4', '01/01/2001', 'U', 9288)
```

查看内存占用，它应该远高于 (b) 部分。

## (d) 其他数据结构的内存占用

Python 提供许多表示数据结构的方式。例如：

```python
# A tuple
row = (route, date, daytype, rides)

# A dictionary
row = {
    'route': route,
    'date': date,
    'daytype': daytype,
    'rides': rides,
}

# A class
class Row:
    def __init__(self, route, date, daytype, rides):
        self.route = route
        self.date = date
        self.daytype = daytype
        self.rides = rides

# A named tuple
from collections import namedtuple
Row = namedtuple('Row', ['route', 'date', 'daytype', 'rides'])

# A class with __slots__
class Row:
    __slots__ = ['route', 'date', 'daytype', 'rides']
    def __init__(self, route, date, daytype, rides):
        self.route = route
        self.date = date
        self.daytype = daytype
        self.rides = rides
```
任务如下：为 `read_rides()` 编写不同版本，分别用这些数据结构表示一行数据，然后测量每种方案的内存占用。找出一次处理大量数据时存储效率最高的方式。
