# 练习 3.8

*目标：*

- 了解混入类和协作式继承

*修改文件：* `tableformat.py`

## (a) 列格式化的难题

回到[练习 3.1](ex3_1.md)，`print_portfolio()` 生成了如下表格：

```python
>>> portfolio = read_portfolio('Data/portfolio.csv')
>>> print_portfolio(portfolio)
      name     shares      price
---------- ---------- ---------- 
        AA        100      32.20
       IBM         50      91.10
       CAT        150      83.44
      MSFT        200      51.23
        GE         95      40.37
      MSFT         50      65.10
       IBM        100      70.44
>>>
```

最近几个练习开发的 `print_table()` 几乎能替代这个功能，但还有一个问题：无法精确控制每列内容的格式。例如，`price` 列需要保留两位小数，而 `TableFormatter` 及相关子类做不到。

一种解决方式是修改 `print_table()`，增加格式参数。例如：

```python
>>> def print_table(records, fields, formats, formatter):
        formatter.headings(fields)
        for r in records:
            rowdata = [(fmt % getattr(r, fieldname))
	               for fieldname,fmt in zip(fields,formats)]
            formatter.row(rowdata)

>>> import stock, reader
>>> portfolio = reader.read_csv_as_instances('Data/portfolio.csv', stock.Stock)
>>> from tableformat import TextTableFormatter
>>> formatter = TextTableFormatter()
>>> print_table(portfolio, 
                ['name','shares','price'],
                ['%s','%d','%0.2f'],
                formatter)

      name     shares      price
---------- ---------- ---------- 
        AA        100      32.20
       IBM         50      91.10
       CAT        150      83.44
      MSFT        200      51.23
        GE         95      40.37
      MSFT         50      65.10
       IBM        100      70.44
>>>
```

确实可以这样修改，但这是否合适？所有 `TableFormatter` 类的初衷都是用于不同应用。列格式化也可能在其他地方有用，不应局限于 `print_table()`。

另一种方案是修改 `TableFormatter` 的接口，例如增加第三个方法来应用格式：

```python
class TableFormatter:
    def headings(self, headers):
        ...
    def format(self, rowdata):
        ...
    def row(self, rowdata):
        ...
```

问题在于，每次改变类接口，都必须重构全部现有相关代码。具体而言，要修改所有已编写的 `TableFormatter` 子类以及使用它们的代码。还是别这样做。

另一种选择是让用户通过继承定制某个格式化器，注入格式化操作。例如，做以下实验：

```python
>>> from tableformat import TextTableFormatter, print_table
>>> class PortfolioFormatter(TextTableFormatter):
        def row(self, rowdata):
            formats = ['%s','%d','%0.2f']
            rowdata = [(fmt % d) for fmt, d in zip(formats, rowdata)]
            super().row(rowdata)

>>> formatter = PortfolioFormatter()
>>> print_table(portfolio, ['name','shares','price'], formatter)
      name     shares      price
---------- ---------- ---------- 
        AA        100      32.20
       IBM         50      91.10
       CAT        150      83.44
      MSFT        200      51.23
        GE         95      40.37
      MSFT         50      65.10
       IBM        100      70.44
>>>
```
这样可行，但有些笨拙和奇怪。用户必须选定一个具体格式化器，还得自己实现列格式化代码。应该有更好的办法。

## (b) 横向组合

在 `tableformat.py` 中添加以下类：

```python
class ColumnFormatMixin:
    formats = []
    def row(self, rowdata):
        rowdata = [(fmt % d) for fmt, d in zip(self.formats, rowdata)]
        super().row(rowdata)
```

该类仅包含一个 `row()`，用于格式化行内容，类变量 `formats` 保存格式代码。通过多重继承使用此类。例如：

```python
>>> import stock, reader
>>> portfolio = reader.read_csv_as_instances('Data/portfolio.csv', stock.Stock)
>>> from tableformat import TextTableFormatter, ColumnFormatMixin, print_table
>>> class PortfolioFormatter(ColumnFormatMixin, TextTableFormatter):
        formats = ['%s', '%d', '%0.2f']

>>> formatter = PortfolioFormatter()
>>> print_table(portfolio, ['name','shares','price'], formatter)
      name     shares      price
---------- ---------- ---------- 
        AA        100      32.20
       IBM         50      91.10
       CAT        150      83.44
      MSFT        200      51.23
        GE         95      40.37
      MSFT         50      65.10
       IBM        100      70.44
```

这种方法之所以有效，是因为 `ColumnFormatMixin` 会与提供所需 `row()` 方法的其他类混合使用。

再创建一个类，使格式化器将表头全部输出为大写：

```python
class UpperHeadersMixin:
    def headings(self, headers):
        super().headings([h.upper() for h in headers])
```

试试看，注意表头现在是大写的：

```python
>>> from tableformat import TextTableFormatter, UpperHeadersMixin
>>> class PortfolioFormatter(UpperHeadersMixin, TextTableFormatter):
        pass

>>> formatter = PortfolioFormatter()
>>> print_table(portfolio, ['name','shares','price'], formatter)
      NAME     SHARES      PRICE 
---------- ---------- ---------- 
        AA        100       32.2 
       IBM         50       91.1 
       CAT        150      83.44 
      MSFT        200      51.23 
        GE         95      40.37 
      MSFT         50       65.1 
       IBM        100      70.44 
>>>
```

这就是“混入”（mixin）的核心思想。库作者先提供 `TextTableFormatter`、`CSVTableFormatter` 等基础类，再提供一组附加类，以改变这些类的行为。

## (c) 简化用法

对于框架作者，混入类有助于减少代码量。但让用户记住如何正确组合类和使用多重继承，可能令人头疼。[练习 3.5](ex3_5.md) 的 `create_formatter()` 简化了自定义格式化器的创建。扩展该函数，使其接收几个与混入类有关的可选参数。例如：

```python
>>> from tableformat import create_formatter
>>> formatter = create_formatter('csv', column_formats=['"%s"','%d','%0.2f'])
>>> print_table(portfolio, ['name','shares','price'], formatter)
name,shares,price
"AA",100,32.20
"IBM",50,91.10
"CAT",150,83.44
"MSFT",200,51.23
"GE",95,40.37
"MSFT",50,65.10
"IBM",100,70.44

>>> formatter = create_formatter('text', upper_headers=True)
>>> print_table(portfolio, ['name','shares','price'], formatter)
      NAME     SHARES      PRICE 
---------- ---------- ---------- 
        AA        100       32.2 
       IBM         50       91.1 
       CAT        150      83.44 
      MSFT        200      51.23 
        GE         95      40.37 
      MSFT         50       65.1 
       IBM        100      70.44 
>>>
```

`create_formatter()` 会在内部正确组合各个类，并返回合适的 `TableFormatter` 实例。
