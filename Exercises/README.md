欢迎学习精通 Python 高级编程课程。本目录 `pythonmaster` 包含课堂练习的辅助文件，也是你完成作业的地方。

本课程要求 Python 3.6 或更新版本。如果使用 Python 2，大部分内容仍适用，但需要对部分代码稍作修改。

- [`PythonMastery.pdf`](../PythonMastery.pdf) 包含全部演示幻灯片，保留为英文原版。

- [`Exercises/`](index.md) 包含全部课堂练习。

- [`Data/`](../Data/) 包含练习使用的数据文件、脚本和其他文件。

- [`Solutions/`](../Solutions/) 包含各练习的完整解答代码。每题都有独立目录，例如练习 3.2 的解答位于 [`Solutions/3_2/`](../Solutions/3_2/)。

我们已尽力确保练习正常工作，但仍可能有拼写错误或小问题。如果发现错误，请告知，以便在课程后续版本中修正。
