# 练习 8.5

*目标：*

- 了解受管理的生成器

*新建文件：* `multitask.py`, `server.py`

生成器或协程函数必须由其他代码驱动才能执行。例如，用于迭代的生成器在实际通过 for 循环遍历前什么也不做；同样，一组协程也必须通过调用 `send()` 才会运行。

生成器的高级应用可以用各种不同寻常的方式驱动生成器。本练习介绍几个例子。

## (a) 将生成器用作任务

在 `multitask.py` 中定义以下代码：

```python
# multitask.py

from collections import deque

tasks = deque()
def run():
    while tasks:
        task = tasks.popleft()
        try:
            task.send(None)
            tasks.append(task)
        except StopIteration:
            print('Task done')
```

它实现了运行生成器函数的微型任务调度器。尝试用它运行以下函数。

```python
# multitask.py
...

def countdown(n):
    while n > 0:
        print('T-minus', n)
        yield
        n -= 1

def countup(n):
    x = 0
    while x < n:
        print('Up we go', x)
        yield
        x += 1

if __name__ == '__main__':
    tasks.append(countdown(10))
    tasks.append(countdown(5))
    tasks.append(countup(20))
    run()
```

## (b) 将生成器用作处理网络连接的任务

创建 `server.py`，写入以下代码：

```python
# server.py

from socket import *
from select import select
from collections import deque

tasks = deque()
recv_wait = {}   #  sock -> task
send_wait = {}   #  sock -> task

def run():
    while any([tasks, recv_wait, send_wait]):
        while not tasks:
            can_recv, can_send, _ = select(recv_wait, send_wait, [])
            for s in can_recv:
                tasks.append(recv_wait.pop(s))
            for s in can_send:
                tasks.append(send_wait.pop(s))
        task = tasks.popleft()
        try:
            reason, resource = task.send(None)
            if reason == 'recv':
                recv_wait[resource] = task
            elif reason == 'send':
                send_wait[resource] = task
            else:
                raise RuntimeError('Unknown reason %r' % reason)
        except StopIteration:
            print('Task done')
```

它是 (a) 部分任务调度器的稍复杂版本，需要仔细研究。核心思路是，每个任务不仅让出执行权，还说明原因：接收或发送。任务据此移入等待区，调度器运行可用任务；无事可做时则等待 I/O 事件。

可能有些复杂。添加以下代码，实现简单的回显服务器：

```python
# server.py
...

def tcp_server(address, handler):
    sock = socket(AF_INET, SOCK_STREAM)
    sock.setsockopt(SOL_SOCKET, SO_REUSEADDR, 1)
    sock.bind(address)
    sock.listen(5)
    while True:
        yield 'recv', sock
        client, addr = sock.accept()
        tasks.append(handler(client, addr))
        
def echo_handler(client, address):
    print('Connection from', address)
    while True:
        yield 'recv', client
        data = client.recv(1000)
        if not data:
            break
        yield 'send', client
        client.send(b'GOT:' + data)
    print('Connection closed')

if __name__ == '__main__':
    tasks.append(tcp_server(('',25000), echo_handler))
    run()
```

在独立终端运行服务器；从另一个终端用 `telnet` 或 `nc` 连接。例如：

```
bash % nc localhost 25000
Hello
Got: Hello
World
Got: World
```

如果没有 `nc` 或 `telnet`，也可以使用 Python：

```
bash % python3 -m telnetlib localhost 25000
Hello
Got: Hello
World
Got: World
```

正常时，应看到发送内容被回显。而且多个客户端连接后，所有连接都能并发运行。

你通常不必直接编写这种巧妙使用生成器的代码，但某些高级包会使用这些技术，例如 Python 3.4 加入标准库的 `asyncio`。
