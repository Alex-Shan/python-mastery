# 练习 3.5

*目标：*

- 学会通过继承编写可扩展代码。
- 编写可按用户选择输出纯文本、CSV、HTML 等不同格式的程序，了解继承的实际用途。

*修改文件：* `tableformat.py`

Python 类的主要用途之一，是编写能以各种方式扩展或适配的代码。例如，[练习 3.2](ex3_2.md) 的 `print_table()` 用于生成表格，你已用它输出 `portfolio` 列表：

```python
>>> import stock
>>> import reader
>>> import tableformat
>>> portfolio = reader.read_csv_as_instances('Data/portfolio.csv', stock.Stock)
>>> tableformat.print_table(portfolio, ['name','shares','price'])
      name     shares      price
---------- ---------- ---------- 
        AA        100       32.2
       IBM         50       91.1
       CAT        150      83.44
      MSFT        200      51.23
        GE         95      40.37
      MSFT         50       65.1
       IBM        100      70.44
>>> 
```

假设希望 `print_table()` 支持 CSV、XML、HTML、Excel 等任意数量的格式。直接修改函数以同时支持所有格式会很痛苦。更好的办法是将输出格式相关代码移到类中，再通过继承实现不同输出格式。

## (a) 定义通用格式化器类

在 `tableformat.py` 中添加以下类定义：

```python
class TableFormatter:
    def headings(self, headers):
        raise NotImplementedError()

    def row(self, rowdata):
        raise NotImplementedError()
```

修改 `print_table()`，使其接收一个 `TableFormatter` 实例，通过调用其方法生成输出：

```python
def print_table(records, fields, formatter):
    formatter.headings(fields)
    for r in records:
        rowdata = [getattr(r, fieldname) for fieldname in fields]
        formatter.row(rowdata)
```

这两部分代码需要配合使用。例如：

```
>>> import stock, reader, tableformat
>>> portfolio = reader.read_csv_as_instances('Data/portfolio.csv', stock.Stock)
>>> formatter = tableformat.TableFormatter()
>>> tableformat.print_table(portfolio, ['name', 'shares', 'price'], formatter)
Traceback (most recent call last):
...
NotImplementedError
>>>
```

目前它还没什么实际作用，下一部分将解决这一点。

## (b) 实现具体格式化器

`TableFormatter` 并非供直接使用，而是作为实现格式化功能的其他类的基类。在 `tableformat.py` 中添加以下类：

```python
class TextTableFormatter(TableFormatter):
    def headings(self, headers):
        print(' '.join('%10s' % h for h in headers))
        print(('-'*10 + ' ')*len(headers))
    
    def row(self, rowdata):
        print(' '.join('%10s' % d for d in rowdata))
```

现在这样使用新类：

```python
>>> import stock, reader, tableformat
>>> portfolio = reader.read_csv_as_instances('Data/portfolio.csv', stock.Stock)
>>> formatter = tableformat.TextTableFormatter()
>>> tableformat.print_table(portfolio, ['name','shares','price'], formatter)
     name     shares      price
---------- ---------- ---------- 
        AA        100       32.2
       IBM         50       91.1
       CAT        150      83.44
      MSFT        200      51.23
        GE         95      40.37
      MSFT         50       65.1
       IBM        100      70.44
>>> 
```

## (d) 简化选择

继承带来的一个问题是，选择不同的类会增加复杂度，例如需要记住名称、使用正确的 `import` 语句等。工厂函数可以简化这一过程。在 `tableformat.py` 添加 `create_formatter()`，允许用户通过 `'text'`、`'csv'` 或 `'html'` 等格式名称创建格式化器。例如：

```python
>>> from tableformat import create_formatter, print_table
>>> formatter = create_formatter('html')
>>> print_table(portfolio, ['name','shares','price'], formatter)
<tr> <th>name</th> <th>shares</th> <th>price</th> </tr>
<tr> <td>AA</td> <td>100</td> <td>32.2</td> </tr>
<tr> <td>IBM</td> <td>50</td> <td>91.1</td> </tr>
<tr> <td>CAT</td> <td>150</td> <td>83.44</td> </tr>
<tr> <td>MSFT</td> <td>200</td> <td>51.23</td> </tr>
<tr> <td>GE</td> <td>95</td> <td>40.37</td> </tr>
<tr> <td>MSFT</td> <td>50</td> <td>65.1</td> </tr>
<tr> <td>IBM</td> <td>100</td> <td>70.44</td> </tr>
>>>
```

**讨论**

本练习的 `TableFormatter` 是“抽象基类”（abstract base class）的例子。它并不用于直接实例化，而是为程序组件（这里是各种输出格式）定义接口。生成表格的代码针对抽象基类编写，由用户提供合适的实现。只要所有必需的方法均已实现，一切就应该能正常工作——但愿如此。
