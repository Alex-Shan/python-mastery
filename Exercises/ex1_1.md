# 练习 1.1

*目标：*

- 确认机器已正确安装 Python
- 启动交互式解释器
- 编辑并运行一个小程序

*新建文件：* `art.py`

## (a) 启动 Python

在机器上启动 Python 3，确认能够输入简单语句，例如“hello world”程序：

```python
>>> print('Hello World')
Hello World
>>>
```

本课程的大部分内容都需要像这样使用交互式读取—求值—输出循环（REPL）。使用 IPython 或 Jupyter Notebook 等其他环境也可以。

## (b) 生成艺术

创建以下程序，将其保存到 `art.py` 文件中：

```python
# art.py

import sys
import random

chars = '\|/'

def draw(rows, columns):
    for r in rows:
        print(''.join(random.choice(chars) for _ in range(columns)))

if __name__ == '__main__':
    if len(sys.argv) != 3:
        raise SystemExit("Usage: art.py rows columns")
    draw(int(sys.argv[1]), int(sys.argv[2]))
```

确认可以从命令行或终端运行这个程序。

```
bash % python3 art.py 10 20
```

运行以上命令会使程序崩溃并显示异常回溯。修复问题后再次运行，应该得到类似以下的输出：

```
bash % python3 art.py 10 20

///||\/||\//|\\|\\/\

|//\||\/|\///|\|\|/|

//\//|/|\\|\//\|||\/

bash %
```
