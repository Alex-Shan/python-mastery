# 练习 4.4

*目标：*

- 了解属性访问的定制
- 委托与继承的比较

## (a) 槽与 setattr

前面的练习用 `__slots__` 列出类的实例属性。槽的主要目的是优化内存，附带效果是将允许的属性严格限制在列表内。缺点是它与 Python 其他部分的交互有时很奇怪，例如使用槽的类不能用于多重继承。因此，除特殊情况外，不应使用槽。

如果确实要限制允许的属性集合，另一种方法是定义 `__setattr__()`。试试这个实验：

```python
>>> class Stock:
        def __init__(self, name, shares, price):
            self.name = name
            self.shares = shares
            self.price = price
        def __setattr__(self, name, value):
            if name not in { 'name', 'shares', 'price' }:
                raise AttributeError('No attribute %s' % name)
            super().__setattr__(name, value)

>>> s = Stock('GOOG', 100, 490.1)
>>> s.name
'GOOG'
>>> s.shares = 75
>>> s.share = 50
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
  File "<stdin>", line 8, in __setattr__
AttributeError: No attribute share
>>> 
```

这里没有槽，但 `__setattr__()` 仍将属性限制在预定义集合中。不过，需要考虑它与继承的交互。例如，子类若想添加新属性，可能需要重定义 `__setattr__()`。

## (b) 代理

代理类（proxy class）包装一个现有类，并提供类似接口。定义以下类，为现有对象加上只读层：

```python
>>> class Readonly:
        def __init__(self, obj):
            self.__dict__['_obj'] = obj
        def __setattr__(self, name, value):
            raise AttributeError("Can't set attribute")
        def __getattr__(self, name):
            return getattr(self._obj, name)

>>>
```

使用时，只需包装现有实例：

```python
>>> from stock import Stock
>>> s = Stock('GOOG', 100, 490.1)
>>> p = Readonly(s)
>>> p.name
'GOOG'
>>> p.shares
100
>>> p.cost
49010.0
>>> p.shares = 50
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
  File "<stdin>", line 8, in __setattr__
AttributeError: Can't set attribute
>>> 
```

## (c) 用委托代替继承

委托（delegation）有时用于代替继承，其思路与 (b) 部分的代理类几乎相同。尝试定义以下类：

```python
>>> class Spam:
        def a(self):
            print('Spam.a')
        def b(self):
            print('Spam.b')

>>>
```

再创建一个包装它并重定义部分方法的类：

```python
>>> class MySpam:
        def __init__(self):
            self._spam = Spam()
        def a(self):
            print('MySpam.a')
            self._spam.a()
        def c(self):
            print('MySpam.c')
        def __getattr__(self, name):
            return getattr(self._spam, name)

>>> s = MySpam()
>>> s.a()
MySpam.a
Spam.a
>>> s.b()
Spam.b
>>> s.c()
MySpam.c
>>>
```

注意，最终的类看起来很像继承。例如，`a()` 做了类似 `super()` 调用的操作；`b()` 则通过 `__getattr__()` 获取，由该方法委托给内部的 `Spam` 实例。

**讨论**

包装其他对象的类通常会定义 `__getattr__()`。不过，这种包装常常带来其他复杂性。例如，如果应用其他部分使用 `isinstance()`，包装对象可能导致类型检查失效。

通过 `__getattr__()` 委托方法，也不适用于 `__getitem__()`、`__enter__()` 等特殊方法。如果某类大量使用特殊方法，就必须在包装类中提供类似功能。
