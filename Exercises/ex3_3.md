# 练习 3.3

*目标：*

- 了解类变量和类方法

*修改文件：* `stock.py`, `reader.py`

之前定义的 `Stock` 类通常这样创建实例：

```python
>>> s = Stock('GOOG', 100, 490.1)
>>>
```

不过，`read_portfolio()` 也会从文件读取的数据行创建实例。例如使用如下代码：

```python
>>> import csv
>>> f = open('Data/portfolio.csv')
>>> rows = csv.reader(f)
>>> headers = next(rows)
>>> row = next(rows)
>>> row
['AA', '100', '32.20']
>>> s = Stock(row[0], int(row[1]), float(row[2]))
>>>
```

## (a) 替代构造器

也许从原始数据行创建 `Stock` 的过程更适合交给替代构造器。修改 `Stock`，加入 `types` 类变量和 `from_row()` 类方法：

```python
class Stock:
    types = (str, int, float)
    def __init__(self, name, shares, price):
        self.name = name
        self.shares = shares
        self.price = price

    @classmethod
    def from_row(cls, row):
        values = [func(val) for func, val in zip(cls.types, row)]
        return cls(*values)
    ...
```

测试方式如下：

```python
>>> row = ['AA', '100', '32.20']
>>> s = Stock.from_row(row)
>>> s.name
'AA'
>>> s.shares
100
>>> s.price
32.2
>>> s.cost()
3220.0000000000005
>>>
```

仔细观察，行中的字符串值已转换为适当的类型。

## (b) 类变量与继承

使用继承时，`types` 这样的类变量有时可用于定制行为。例如，`Stock` 的类型可以在子类中轻松修改。试试以下例子，将 `price` 改为通常更适合财务计算的 `Decimal` 实例：

```python
>>> from decimal import Decimal
>>> class DStock(Stock):
        types = (str, int, Decimal)

>>> row = ['AA', '100', '32.20']
>>> s = DStock.from_row(row)
>>> s.price
Decimal('32.20')
>>> s.cost()
Decimal('3220.0')
>>>
```

**设计讨论**

本练习解决的是文件读取后的数据转换问题。改为在 `Stock` 的 `__init__()` 中完成转换，是否合理？例如：

```python
class Stock:
    def __init__(self, name, shares, price):
        self.name = str(name)
        self.shares = int(shares)
        self.price = float(price)
```

这样就可以按以下方式转换一行数据：

```python
>>> row = ['AA', '100', '32.20']
>>> s = Stock(*row)
>>> s.name
'AA'
>>> s.shares
100
>>> s.price
32.2
>>>
```

这是好设计还是坏设计？你怎么看？总体而言，我认为这种设计值得商榷，因为它混合了实例创建与数据转换两件事。此外，`__init__()` 中的隐式转换限制了灵活性，用户稍不注意还可能引入奇怪的错误。

## (d) 通用化

类方法的一项实用特性是，可以为各种类提供高度统一的实例创建接口，并据此编写通用工具函数。

之前创建的 `reader.py` 包含读取 CSV 数据的函数。在其中添加以下 `read_csv_as_instances()`，接收一个类，并通过该类的 `from_row()` 创建实例列表：

```python
# reader.py
...

def read_csv_as_instances(filename, cls):
    '''
    Read a CSV file into a list of instances
    '''
    records = []
    with open(filename) as f:
        rows = csv.reader(f)
        headers = next(rows)
        for row in rows:
            records.append(cls.from_row(row))
    return records
```

删除 `read_portfolio()`，它已不再需要。要读取 `Stock` 对象列表，可以这样做：

```python
>>> # Read a portfolio of Stock instances
>>> from reader import read_csv_as_instances
>>> from stock import Stock
>>> portfolio = read_csv_as_instances('Data/portfolio.csv', Stock)
>>> portfolio
[<__main__.Stock object at 0x100674748>, 
<__main__.Stock object at 0x1006746d8>, 
<__main__.Stock object at 0x1006747b8>, 
<__main__.Stock object at 0x100674828>, 
<__main__.Stock object at 0x100674898>, 
<__main__.Stock object at 0x100674908>, 
<__main__.Stock object at 0x100674978>]
>>>
```

下面展示如何将 `read_csv_as_instances()` 用于完全不同的类：

```python
>>> class Row:
         def __init__(self, route, date, daytype, numrides):
             self.route = route
             self.date = date
             self.daytype = daytype
             self.numrides = numrides
         @classmethod
         def from_row(cls, row):
             return cls(row[0], row[1], row[2], int(row[3]))

>>> rides = read_csv_as_instances('Data/ctabus.csv', Row)
>>> len(rides)
577563
>>>
```

**讨论**

本练习展示类变量和类方法的两种最常见用法。类变量通常保存所有实例共享的全局参数，例如配置项。有时，子类继承基类并覆盖该设置，以改变行为。

类方法最常用于实现上述替代构造器。识别这类方法的常见线索是名称中包含“from”。例如，内置字典提供如下用法：

```python
>>> d = dict.fromkeys(['a','b','c'], 0)     # class method
>>> d
{'a': 0, 'c': 0, 'b': 0}
>>>
```
