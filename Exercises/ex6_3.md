# 练习 6.3

*目标：*

- 学习检查函数内部结构

*修改文件：* `structure.py`

## (a) 检查函数

定义一个简单函数：

```python
>>> def add(x,y):
       'Adds two things'
       return x+y

>>>
```

对函数调用 `dir()`，查看其属性。

```python
>>> dir(add)
... look at the result ...
>>>
```

获取函数名、定义它的模块名以及文档字符串等基本信息。

```python
>>> add.__name__
'add'
>>> add.__module__
'__main__'
>>> add.__doc__
'Adds two things'
>>>
```

函数的 `__code__` 属性包含实现的底层信息。尝试从中确定所需参数数量和局部变量名称。

## (b) 使用 inspect 模块

通过 inspect 模块获取函数调用信息：

```python
>>> import inspect
>>> sig = inspect.signature(add)
>>> sig
<Signature (x, y)>
>>> sig.parameters
mappingproxy(OrderedDict([('x', <Parameter "x">), ('y', <Parameter "y">)]))
>>> tuple(sig.parameters)
('x', 'y')
>>>
```

## (c) 整合

[练习 6.1](ex6_1.md) 的 `Structure` 定义了通用的 `__init__()`、`__setattr__()` 和 `__repr__()`，要求用户定义 `_fields` 类变量：

```python
class Stock(Structure):
    _fields = ('name','shares','price')
```

问题在于 `__init__()` 没有适用于帮助信息和关键字参数的有效签名。[练习 6.2](ex6_2.md) 通过特殊的 `self._init()` 做了一个巧妙的变通。例如：

```python
class Stock(Structure):
    _fields = ('name', 'shares', 'price')
    def __init__(self, name, shares, price):
        self._init()
    ...
```

这样虽有了有效签名，但用户必须同时提供 `_fields` 和 `__init__()`，类仍然很奇怪。

任务是通过函数检查技巧消除 `_fields`。先注意，可以这样获取 `Stock` 的参数签名：

```python
>>> import inspect
>>> sig = inspect.signature(Stock)
>>> tuple(sig.parameters)
('name', 'shares', 'price')
>>>
```

也许可以根据 `__init__()` 的签名设置 `_fields`。为 `Structure` 添加类方法 `set_fields(cls)`，检查 `__init__()` 并适当设置 `_fields`。用法如下：

```python
class Stock(Structure):
    def __init__(self, name, shares, price):
        self._init()

    ...

Stock.set_fields()
```

最终的类应与之前行为相同：

```python
>>> s = Stock(name='GOOG', shares=100, price=490.1)
>>> s
Stock('GOOG',100,490.1)
>>> s.shares = 50
>>> s.share = 50
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
  File "structure.py", line 12, in __setattr__
    raise AttributeError('No attribute %s' % name)
AttributeError: No attribute share
>>> 
```

再次用单元测试验证稍作修改的 `Stock`。仍会有失败，但结果不应与上一练习有变化。

目前仍有些“取巧”，但已经取得进展：`Stock` 有了有用的 `__init__()`、表示字符串，以及限制属性名称的 `__setattr__()`。额外调用 `set_fields()` 有些奇怪，稍后会处理。
