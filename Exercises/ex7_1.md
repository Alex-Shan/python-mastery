# 练习 7.1

*目标：*

- 学习定义简单装饰器函数

*新建文件：* `logcall.py`

*修改文件：* `validate.py`

## (a) 第一个装饰器

先写一个_非常_简单的装饰器函数，每次调用函数时只输出一条消息。创建 `logcall.py`，定义以下函数：

```python
# logcall.py

def logged(func):
    print('Adding logging to', func.__name__)
    def wrapper(*args, **kwargs):
        print('Calling', func.__name__)
        return func(*args, **kwargs)
    return wrapper
```

再创建独立的 `sample.py`，将它应用到几个函数定义上：

```python
# sample.py

from logcall import logged

@logged
def add(x,y):
    return x+y

@logged
def sub(x,y):
    return x-y
```

按以下方式测试：

```python
>>> import sample
Adding logging to add
Adding logging to sub
>>> sample.add(3,4)
Calling add
7
>>> sample.sub(2,3)
Calling sub
-1
>>> 
```

## (b) 实用的装饰器

[练习 6.5](ex6_5.md) 创建了可调用类 `ValidatedFunction`，强制执行类型注解。将它重写为装饰器函数 `validated`，支持以下代码：

```python
from validate import Integer, validated

@validated
def add(x: Integer, y:Integer) -> Integer:
    return x + y

@validated
def pow(x: Integer, y:Integer) -> Integer:
    return x ** y
```

被装饰函数应有如下行为：

```python
>>> add(2, 3)
5
>>> add('2', '3')
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
  File "validate.py", line 75, in wrapper
    raise TypeError('Bad Arguments\n' + '\n'.join(errors))
TypeError: Bad Arguments
    x: Expected <class 'int'>
    y: Expected <class 'int'>

>>> pow(2, 3)
8
>>> pow(2, -1)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
  File "validate.py", line 83, in wrapper
    raise TypeError(f'Bad return: {e}') from None
TypeError: Bad return: Expected <class 'int'>
>>>
```

装饰器应尝试处理异常，让错误信息像上面一样更有用。另外，`@validated` 应能在类中工作，无需特殊处理。

```python
class Stock:
    def __init__(self, name, shares, price):
        self.name = name
        self.shares = shares
        self.price = price
    
    @property
    def cost(self):
        return self.shares * self.price

    @validated
    def sell(self, nshares:PositiveInteger):
        self.shares -= nshares
```
