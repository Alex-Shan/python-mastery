## (a) 描述符的实际运作

之前创建的 `Stock` 使用了槽、特性等功能，它们均由描述符协议实现。通过以下简单实验观察其运作。

先创建股票对象，尝试查找几个属性：

```python
>>> s = Stock('GOOG', 100, 490.10)
>>> s.name
'GOOG'
>>> s.shares
100
>>>
```

注意，这些属性位于类字典中。

```python
>>> Stock.__dict__.keys()
['sell', '__module__', '__weakref__', 'price', '_price', 'shares', '_shares',
'__slots__', 'cost', '__repr__', '__doc__', '__init__']
>>> 
```

尝试以下步骤，观察描述符如何获取和设置实例的值：

```python
>>> q = Stock.__dict__['shares']
>>> q.__get__(s)
100
>>> q.__set__(s,75)
>>> s.shares
75
>>> q.__set__(s, '75')
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
  File "stock.py", line 23, in shares
    raise TypeError('Expected an integer')
TypeError: Expected an integer
>>>
```

访问实例时，会自动执行 `__get__()` 和 `__set__()`。


## (b) 创建自己的描述符

定义讲义中的描述符类：

```python
# descrip.py

class Descriptor:
    def __init__(self, name):
        self.name = name
    def __get__(self, instance, cls):
        print('%s:__get__' % self.name)
    def __set__(self, instance, value):
        print('%s:__set__ %s' % (self.name, value))
    def __delete__(self, instance):
        print('%s:__delete__' % self.name)
```

再定义一个使用该描述符的简单类：

```python
>>> class Foo:
        a = Descriptor('a')
        b = Descriptor('b')
        c = Descriptor('c')

>>> f = Foo()
>>> f
<__main__.Foo object at 0x38e130> <class __main__.Foo>
>>> f.a
a:__get__
>>> f.b
b:__get__
>>> f.a = 23
a:__set__ 23
>>> del f.a
a:__delete__
>>>
```

思考一下：你已经接管了某个属性的点号运算。

## (c) 从验证器到描述符

上一练习编写了一系列检查类。例如：

```python
>>> PositiveInteger.check(10)
10
>>> PositiveInteger.check('10')
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
    raise TypeError('Expected %s' % cls.expected_type)
TypeError: expected <class 'int'>
>>> PositiveInteger.check(-10)
```

只需对 `Validator` 基类稍作修改，就可以扩展为描述符。改为如下代码：

```python
# validate.py

class Validator:
    def __init__(self, name):
        self.name = name

    @classmethod
    def check(cls, value):
        return value

    def __set__(self, instance,	value):
        instance.__dict__[self.name] = self.check(value)
```

注意：描述符没有定义 `__get__()`，因此 Python 会使用默认的属性查找实现。这要求提供的名称与实例字典中的名称一致。

无需其他改动。现在修改 `Stock`，将验证器用作描述符：

```python
class Stock:
    name   = String('name')
    shares = PositiveInteger('shares')
    price  = PositiveFloat('price')

    def __init__(self,name,shares,price):
        self.name = name
        self.shares = shares
        self.price = price
```

类的行为与之前相同，代码却少了很多，而且所有所需检查均已具备：

```python
>>> s = Stock('GOOG', 100, 490.10)
>>> s.name
'GOOG'
>>> s.shares
100
>>> s.shares = 75
>>> s.shares = '75'
... TypeError ...
>>> s.shares = -50
... ValueError ...
>>>
```

这很棒！描述符大幅简化了 `Stock` 的实现。它真正的威力就在于提供对点号操作的底层控制，并可据此实现许多强大功能。

## (d) 解决重复名称

描述符的一个烦人之处是必须重复指定名称。例如：

```python
class Stock:
    ...
    shares = PositiveInteger('shares')
    ...
```

可以解决。修改顶层 `Validator` 类，添加如下 `__set_name__()`：

```python
# validate.py

class Validator:
    def __init__(self, name=None):
        self.name = name

    def __set_name__(self, cls, name):
        self.name = name

    @classmethod
    def check(cls, value):
        return value

    def __set__(self, instance,	value):
        instance.__dict__[self.name] = self.check(value)
```

现在尝试将 `Stock` 重写为：

```python
class Stock:
    name   = String()
    shares = PositiveInteger()
    price  = PositiveFloat()

    def __init__(self,name,shares,price):
        self.name = name
        self.shares = shares
        self.price = price
```

这样好多了。不过请注意，这种设置名称的能力是 Python 3.6 的特性，旧版本不支持。
