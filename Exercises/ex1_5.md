# 练习 1.5

*目标：*

- 复习如何定义一个简单对象

*新建文件：* `stock.py`

## (a) 定义简单对象

创建 `stock.py` 文件并定义以下类：

```python
class Stock:
    def __init__(self, name, shares, price):
        self.name = name
        self.shares = shares
        self.price = price
    def cost(self):
        return self.shares * self.price
```

完成后，运行程序，试用新的 `Stock` 对象：

```python
>>> s = Stock('GOOG',100,490.10)
>>> s.name
'GOOG'
>>> s.shares
100
>>> s.price
490.1
>>> s.cost()
49010.0
>>> print('%10s %10d %10.2f' % (s.name, s.shares, s.price))
      GOOG        100     490.10
>>> t = Stock('IBM', 50, 91.5)
>>> t.cost()
4575.0
>>> 
```
