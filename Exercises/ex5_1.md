## (a) 回归基础

先撤销与类定义有关的改动。重写 `reader.py`，恢复为引入类之前的两个基本函数：

```python
# reader.py

import csv

def read_csv_as_dicts(filename, types):
    '''
    Read CSV data into a list of dictionaries with optional type conversion
    '''
    records = []
    with open(filename) as file:
        rows = csv.reader(file)
        headers = next(rows)
        for row in rows:
            record = { name: func(val) 
                       for name, func, val in zip(headers, types, row) }
            records.append(record)
    return records

def read_csv_as_instances(filename, cls):
    '''
    Read CSV data into a list of instances
    '''
    records = []
    with open(filename) as file:
        rows = csv.reader(file)
        headers = next(rows)
        for row in rows:
            record = cls.from_row(row)
            records.append(record)
    return records
```

确保代码仍像以前一样工作：


## (b) 思考灵活性

目前，`reader.py` 的两个函数仅支持直接传给 `open()` 的文件名。重构代码，使其支持任何能产生文本行的可迭代对象。创建 `csv_as_dicts(lines, types)` 和 `csv_as_instances(lines, cls)`，转换任意可迭代的文本行序列。例如：

```python
>>> file = open('Data/portfolio.csv')
>>> port = reader.csv_as_dicts(file, [str, int, float])
>>> port
[{'name': 'AA', 'shares': 100, 'price': 32.2}, {'name': 'IBM', 'shares': 50, 'price': 91.1}, 
 {'name': 'CAT', 'shares': 150, 'price': 83.44}, {'name': 'MSFT', 'shares': 200, 'price': 51.23}, 
 {'name': 'GE', 'shares': 95, 'price': 40.37}, {'name': 'MSFT', 'shares': 50, 'price': 65.1}, 
 {'name': 'IBM', 'shares': 100, 'price': 70.44}]
>>>
```

这样做是为了支持不同输入来源。例如：

```python
>>> import gzip
>>> import stock
>>> file = gzip.open('Data/portfolio.csv.gz', 'rt')
>>> port = reader.csv_as_instances(file, stock.Stock)
>>> port
[Stock('AA', 100, 32.2), Stock('IBM', 50, 91.1), Stock('CAT', 150, 83.44), 
 Stock('MSFT', 200, 51.23), Stock('GE', 95, 40.37), Stock('MSFT', 50, 65.1), 
 Stock('IBM', 100, 70.44)]
>>>
```

为兼容旧代码，仍提供接收文件名的 `read_csv_as_dicts()` 和 `read_csv_as_instances()`。它们调用 `open()` 打开文件，再将文件交给新的 `csv_as_dicts()` 或 `csv_as_instances()`。

## (d) API 挑战：类型提示

函数参数和返回值可以附带可选的类型提示（type hint）。例如：

```python
def add(x:int, y:int) -> int:
    return x + y
```

`typing` 模块还提供类，用于表示容器等更复杂的类型。例如：

```python
from typing import List

def sum_squares(nums: List[int]) -> int:
    total = 0
    for n in nums:
        total += n*n
    return total
```

挑战：为 `reader.py` 的所有函数添加尽可能准确的类型提示。可能需要查阅 [typing 模块文档](https://docs.python.org/3/library/typing.html)。
