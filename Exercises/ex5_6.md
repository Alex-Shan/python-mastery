# 练习 5.6

*目标：*

- 学习使用 Python 的 unittest 模块

*新建文件：* `teststock.py`

本练习探索 Python `unittest` 模块的基本使用机制。

## (a) 准备工作

之前的练习创建了包含 `Stock` 类的 `stock.py`。在独立的 `teststock.py` 中定义以下测试代码：

```python
# teststock.py

import unittest
import stock

class TestStock(unittest.TestCase):
    def test_create(self):
        s = stock.Stock('GOOG', 100, 490.1)
        self.assertEqual(s.name, 'GOOG')
        self.assertEqual(s.shares, 100)
        self.assertEqual(s.price, 490.1)

if __name__ == '__main__':
    unittest.main()
```

确认可以运行此文件：

```
 bash % python3 teststock.py
 .
 ------------------------------------------------------------------```
 Ran 1 tests in 0.001s

 OK
 bash %
```

## (b) 单元测试

参考 `teststock.py` 的代码，为 `TestStock` 添加以下测试：

- 测试可以通过 `Stock(name='GOOG',shares=100,price=490.1)` 等关键字参数创建 `Stock`。
- 测试 `cost` 特性返回正确的值。
- 测试 `sell()` 正确更新股数。
- 测试 `from_row()` 类方法能从正确数据创建新实例。
- 测试 `__repr__()` 生成适当的表示字符串。
- 测试比较运算符方法 `__eq__()`。

## (c) 测试预期异常

如果要编写检查异常的单元测试，可以这样做：

```python
class TestStock(unittest.TestCase):
    ...
    def test_bad_shares(self):
        s = stock.Stock('GOOG', 100, 490.1)
        with self.assertRaises(TypeError):
             s.shares = '50'
    ...
```

参考该测试，为以下失败情形编写单元测试：

- 测试将 `shares` 设为字符串时抛出 `TypeError`。
- 测试将 `shares` 设为负数时抛出 `ValueError`。
- 测试将 `price` 设为字符串时抛出 `TypeError`。
- 测试将 `price` 设为负数时抛出 `ValueError`。
- 测试设置不存在的 `share` 属性时抛出 `AttributeError`。
