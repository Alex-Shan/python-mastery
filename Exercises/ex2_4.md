# 练习 2.4

*目标：*

- 创建新的基本类型

大多数程序使用 `int`、`float`、`str` 等基本类型表示数据，但并不限于这些类型。标准库中的 `decimal` 和 `fractions` 等模块实现了新的基本类型。只要理解 Python 对象背后的协议，也可以创建自己的类型。本练习将创建一种新的基本类型。虽然需要处理许多细节，但可以借此了解总体要求。

## (a) 可变整数

Python 整数通常不可变。如果想创建可变的整数对象，可以先定义以下类：

```python
# mutint.py

class MutInt:
    __slots__ = ['value']

    def __init__(self, value):
        self.value = value
```

试试看：

```python
>>> a = MutInt(3)
>>> a
<__main__.MutInt object at 0x10e79d408>
>>> a.value
3
>>> a.value = 42
>>> a.value
42
>>> a + 10
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: unsupported operand type(s) for +: 'MutInt' and 'int'
>>>
```

看起来很有趣，但新的 `MutInt` 对象几乎什么都做不了：输出难看，数学运算符不起作用，基本没什么用。不过，它的值确实是可变的。

## (b) 改善输出

为对象定义 `__str__()`、`__repr__()` 和 `__format__()` 等方法即可改善输出。例如：

```python
# mint.py

class MutInt:
    __slots__ = ['value']

    def __init__(self, value):
        self.value = value

    def __str__(self):
        return str(self.value)

    def __repr__(self):
        return f'MutInt({self.value!r})'

    def __format__(self, fmt):
        return format(self.value, fmt)
```

试试看：

```python
>>> a = MutInt(3)
>>> print(a)
3
>>> a
MutInt(3)
>>> f'The value is {a:*^10d}'
The value is ****3*****
>>> a.value = 42
>>> a
MutInt(42)
>>>
```

## (c) 数学运算符

实现适当的方法，可以让对象支持各种数学运算符。不过，识别其他数据类型并实现相应转换代码是你的责任。为 `MutInt` 类添加如下 `__add__()` 方法：

```python
class MutInt:
    __slots__ = ['value']

    def __init__(self, value):
        self.value = value

    ...

    def __add__(self, other):
        if isinstance(other, MutInt):
            return MutInt(self.value + other.value)
        elif isinstance(other, int):
            return MutInt(self.value + other)
        else:
            return NotImplemented
```

修改后，整数和可变整数都可以相加，结果是一个 `MutInt` 实例。与其他类型的数值相加会报错：

```python
>>> a = MutInt(3)
>>> b = a + 10
>>> b
MutInt(13)
>>> b.value = 23
>>> c = a + b
>>> c
MutInt(26)
>>> a + 3.5
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: unsupported operand type(s) for +: 'MutInt' and 'float'
>>> 
```

这段代码有个问题：操作数顺序反过来时就无法工作。例如：

```python
>>> a + 10
MutInt(13)
>>> 10 + a
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: unsupported operand type(s) for +: 'int' and 'MutInt'
>>> 
```

原因是 `int` 类型不了解 `MutInt`，无法处理。添加 `__radd__()` 方法即可解决。如果第一次调用 `__add__()` 无法处理给定对象，就会调用这个方法。

```python
class MutInt:
    __slots__ = ['value']

    def __init__(self, value):
        self.value = value

    ...

    def __add__(self, other):
        if isinstance(other, MutInt):
            return MutInt(self.value + other.value)
        elif isinstance(other, int):
            return MutInt(self.value + other)
        else:
            return NotImplemented

    __radd__ = __add__    # Reversed operands
```

修改后，加法可以正常工作：

```python
>>> a = MutInt(3)
>>> a + 10
MutInt(13)
>>> 10 + a
MutInt(13)
>>>
```

因为整数是可变的，还可以实现 `__iadd__()`，使其支持就地加法更新运算符 `+=`：

```python
class MutInt:
    __slots__ = ['value']

    def __init__(self, value):
        self.value = value

    ...

    def __iadd__(self, other):
        if isinstance(other, MutInt):
            self.value += other.value
            return self
        elif isinstance(other, int):
            self.value += other
            return self
        else:
            return NotImplemented
```

这会带来一些有趣的用法：

```python
>>> a = MutInt(3)
>>> b = a
>>> a += 10
>>> a
MutInt(13)
>>> b                 # Notice that b also changes
MutInt(13)
>>>
```

`b` 也发生变化似乎很奇怪，但 Python 内置对象也存在类似的细微行为。例如：

```python
>>> a = [1,2,3]
>>> b = a
>>> a += [4,5]
>>> a
[1, 2, 3, 4, 5]
>>> b
[1, 2, 3, 4, 5]

>>> c = (1,2,3)
>>> d = c
>>> c += (4,5)
>>> c
(1, 2, 3, 4, 5)
>>> d                  # Explain difference from lists
(1, 2, 3)
>>> 
```

## (d) 比较

另一个问题是比较运算仍然不起作用。例如：

```python
>>> a = MutInt(3)
>>> b = MutInt(3)
>>> a == b
False
>>> a == 3
False
>>>
```

可以添加 `__eq__()` 来解决。`__lt__()`、`__le__()`、`__gt__()`、`__ge__()` 等方法则用于实现其他比较。例如：

```python
class MutInt:
    __slots__ = ['value']

    def __init__(self, value):
        self.value = value

    ...
    def __eq__(self, other):
        if isinstance(other, MutInt):
            return self.value == other.value
        elif isinstance(other, int):
            return self.value == other
        else:
            return NotImplemented
        
    def __lt__(self, other):
        if isinstance(other, MutInt):
            return self.value < other.value
        elif isinstance(other, int):
            return self.value < other
        else:
            return NotImplemented
```

试一下：

```python
>>> a = MutInt(3)
>>> b = MutInt(3)
>>> a == b
True
>>> c = MutInt(4)
>>> a < c
True
>>> a <= c
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: '<=' not supported between instances of 'MutInt' and 'MutInt'
>>> 
```

`<=` 失败是因为没有提供 `__le__()`。可以单独编写，但更简单的方法是使用 `@total_ordering` 装饰器：

```python
from functools import total_ordering

@total_ordering
class MutInt:
    __slots__ = ['value']

    def __init__(self, value):
        self.value = value

    ...

    def __eq__(self, other):
        if isinstance(other, MutInt):
            return self.value == other.value
        elif isinstance(other, int):
            return self.value == other
        else:
            return NotImplemented
        
    def __lt__(self, other):
        if isinstance(other, MutInt):
            return self.value < other.value
        elif isinstance(other, int):
            return self.value < other
        else:
            return NotImplemented
```

只要至少提供相等运算符和另一种比较关系，`@total_ordering` 就会补齐缺失的比较方法。

## (e) 类型转换

新的基本类型已接近完成。你可能希望它支持一些常见的转换。例如：

```python
>>> a = MutInt(3)
>>> int(a)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: int() argument must be a string, a bytes-like object or a number, not 'MutInt'
>>> float(a)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: float() argument must be a string, a bytes-like object or a number, not 'MutInt'
>>>
```

为类添加 `__int__()` 和 `__float__()` 方法即可：

```python
from functools import total_ordering

@total_ordering
class MutInt:
    __slots__ = ['value']

    def __init__(self, value):
        self.value = value

    ...

    def __int__(self):
        return self.value

    def __float__(self):
        return float(self.value)
```

现在可以正确转换了：

```python
>>> a = MutInt(3)
>>> int(a)
3
>>> float(a)
3.0
>>>
```

但通常 Python 不会自动转换数据。因此，即使定义了 `__int__()`，`MutInt` 仍不能用于所有要求整数的场景。例如，索引操作：

```python
>>> names = ['Dave', 'Guido', 'Paula', 'Thomas', 'Lewis']
>>> a = MutInt(1)
>>> names[a]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: list indices must be integers or slices, not MutInt
>>> 
```

为 `MutInt` 添加返回整数的 `__index__()` 即可解决。按以下方式修改类：

```python
from functools import total_ordering

@total_ordering
class MutInt:
    __slots__ = ['value']

    def __init__(self, value):
        self.value = value

    ...

    def __int__(self):
        return self.value

    __index__ = __int__     # Make indexing work
```


**讨论**

创建新的基本数据类型实际上是 Python 中最复杂的编程任务之一。需要考虑大量边界情况和底层问题，尤其是与其他 Python 类型的交互。关键在于：了解底层协议后，几乎可以定制对象与 Python 其余部分交互的所有方面。如果准备这样做，建议先参考与你的目标类似的现有实现。
