# 练习 2.3

*目标：*

- 熟练运用迭代

*修改文件：* None.

迭代（iteration）是必备的 Python 技能。本练习介绍几种常见的迭代惯用法。

先从 CSV 文件获取一些数据行：

```python
>>> import csv
>>> f = open('Data/portfolio.csv')
>>> f_csv = csv.reader(f)
>>> headers = next(f_csv)
>>> headers
['name', 'shares', 'price']
>>> rows = list(f_csv)
>>> from pprint import pprint
>>> pprint(rows)
[['AA', '100', '32.20'],
 ['IBM', '50', '91.10'],
 ['CAT', '150', '83.44'],
 ['MSFT', '200', '51.23'],
 ['GE', '95', '40.37'],
 ['MSFT', '50', '65.10'],
 ['IBM', '100', '70.44']]
>>>
```

## (a) 基本迭代和解包

`for` 语句可以遍历任何数据序列。例如：

```python
>>> for row in rows:
        print(row)

['AA', '100', '32.20']
['IBM', '50', '91.10']
['CAT', '150', '83.44']
['MSFT', '200', '51.23']
['GE', '95', '40.37']
['MSFT', '50', '65.10']
['IBM', '100', '70.44']
>>>
```

如有需要，可以将各个值解包到独立变量：

```python
>>> for name, shares, price in rows:
        print(name, shares, price)

AA 100 32.20
IBM 50 91.10
CAT 150 83.44
MSFT 200 51.23
GE 95 40.37
MSFT 50 65.10
IBM 100 70.44
>>>
```

如果不关心某些值，通常使用 `_` 或 `__` 作为丢弃值的变量。例如：

```python
>>> for name, _, price in rows:
        print(name, price)

AA 32.20
IBM 91.10
CAT 83.44
MSFT 51.23
GE 40.37
MSFT 65.10
IBM 70.44
>>>
```

如果不知道要解包多少个值，可以用 `*` 作为通配符。试试这个按名称分组数据的实验：

```python
>>> from collections import defaultdict
>>> byname = defaultdict(list)
>>> for name, *data in rows:
        byname[name].append(data)

>>> byname['IBM']
[['50', '91.10'], ['100', '70.44']]
>>> byname['CAT']
[['150', '83.44']]
>>> for shares, price in byname['IBM']:
        print(shares, price)

50 91.10
100 70.44
>>>
```

## (b) 使用 enumerate() 计数

如果迭代时需要维护计数器或索引，`enumerate()` 很有用。例如，需要额外的行号时：

```python
>>> for rowno, row in enumerate(rows):
        print(rowno, row)

0 ['AA', '100', '32.20']
1 ['IBM', '50', '91.10']
2 ['CAT', '150', '83.44']
3 ['MSFT', '200', '51.23']
4 ['GE', '95', '40.37']
5 ['MSFT', '50', '65.10']
6 ['IBM', '100', '70.44']
>>>
```

只要注意结构，就可以将其与解包结合使用：

```python
>>> for rowno, (name, shares, price) in enumerate(rows):
        print(rowno, name, shares, price)

0 AA 100 32.20
1 IBM 50 91.10
2 CAT 150 83.44
3 MSFT 200 51.23
4 GE 95 40.37
5 MSFT 50 65.10
6 IBM 100 70.44
>>> 
```

## (c) 使用 zip() 函数

`zip()` 最常用于将数据配对。例如，还记得之前创建的 `headers` 变量：

```python
>>> headers
['name', 'shares', 'price']
>>>
```

把它与其他行数据组合起来可能很有用：

```python
>>> row = rows[0]
>>> row
['AA', '100', '32.20']
>>> for col, val in zip(headers, row):
        print(col, val)

name AA
shares 100
price 32.20
>>>
```

也可以用它构造字典：

```python
>>> dict(zip(headers, row))
{'name': 'AA', 'shares': '100', 'price': '32.20'}
>>>
```

或者构造字典序列：

```python
>>> for row in rows:
        record = dict(zip(headers, row))
        print(record)

{'name': 'AA', 'shares': '100', 'price': '32.20'}
{'name': 'IBM', 'shares': '50', 'price': '91.10'}
{'name': 'CAT', 'shares': '150', 'price': '83.44'}
{'name': 'MSFT', 'shares': '200', 'price': '51.23'}
{'name': 'GE', 'shares': '95', 'price': '40.37'}
{'name': 'MSFT', 'shares': '50', 'price': '65.10'}
{'name': 'IBM', 'shares': '100', 'price': '70.44'}
>>>
```

## (d) 生成器表达式

生成器表达式（generator expression）与列表推导式几乎相同，但不创建列表，而是创建逐步产生结果的对象，通常通过迭代来消费这些结果。试试简单的例子：

```python
>>> nums = [1,2,3,4,5]
>>> squares = (x*x for x in nums)
>>> squares
<generator object <genexpr> at 0x37caa8>
>>> for n in squares:
        print(n)

1
4
9
16
25
>>>
```

注意，生成器表达式只能使用一次。再次执行 for 循环，观察会发生什么：

```python
>>> for n in squares:
        print(n)

>>>
```

使用 `next()` 函数也可以手动逐个获取结果。试试看：

```python
>>> squares = (x*x for x in nums)
>>> next(squares)
1
>>> next(squares)
4
>>> next(squares)
9
>>>
```

继续输入 `next()`，看看没有更多数据时会发生什么。

如果任务更复杂，仍可通过编写生成器函数并使用 `yield` 语句来利用生成器。例如：

```python
>>> def squares(nums):
        for x in nums:
            yield x*x

>>> for n in squares(nums):
        print(n)

1
4
9
16
25
>>>
```

课程稍后会再次介绍生成器函数。目前只需把它们视为能向 `for` 语句提供值的特殊函数。

## (e) 生成器表达式与归约函数

生成器表达式特别适合向 `sum()`、`min()`、`max()`、`any()` 等函数提供数据。使用之前的投资组合数据试试以下例子。注意，与列表推导式相比，这些例子省略了额外的方括号（[]）。

```python
>>> from readport import read_portfolio
>>> portfolio = read_portfolio('Data/portfolio.csv')
>>> sum(s['shares']*s['price'] for s in portfolio)
44671.15
>>> min(s['shares'] for s in portfolio)
50
>>> any(s['name'] == 'IBM' for s in portfolio)
True
>>> all(s['name'] == 'IBM' for s in portfolio)
False
>>> sum(s['shares'] for s in portfolio if s['name'] == 'IBM')
150
>>>
```

下面利用生成器表达式生成逗号分隔的值，用法很巧妙：

```python
>>> s = ('GOOG',100,490.10)
>>> ','.join(s)
... observe that it fails ...
>>> ','.join(str(x) for x in s)    # This works
'GOOG,100,490.1'
>>>
```

上述语法需要适应，关键在于这些操作都不会创建包含全部结果的列表，因此可以节省大量内存。不过，也要避免过度使用复杂语法。

## (f) 节省大量内存

在[练习 2.1](ex2_1.md) 中，`read_rides_as_dicts()` 将 CTA 公交数据读入字典列表，占用大量内存。例如，找出 22 路公交客流最大的日期：

```python
>>> import tracemalloc
>>> tracemalloc.start()
>>> import readrides
>>> rows = readrides.read_rides_as_dicts('Data/ctabus.csv')
>>> rt22 = [row for row in rows if row['route'] == '22']
>>> max(rt22, key=lambda row: row['rides'])
{'date': '06/11/2008', 'route': '22', 'daytype': 'W', 'rides': 26896}
>>> tracemalloc.get_traced_memory()
... look at result. Should be around 220MB
>>>
```

现在试试使用生成器的例子。重启 Python，运行以下代码：

```python
>>> # RESTART
>>> import tracemalloc
>>> tracemalloc.start()
>>> import csv
>>> f = open('Data/ctabus.csv')
>>> f_csv = csv.reader(f)
>>> headers = next(f_csv)
>>> rows = (dict(zip(headers,row)) for row in f_csv)
>>> rt22 = (row for row in rows if row['route'] == '22')
>>> max(rt22, key=lambda row: int(row['rides']))
{'date': '06/11/2008', 'route': '22', 'daytype': 'W', 'rides': 26896}
>>> tracemalloc.get_traced_memory()
... look at result. Should be a LOT smaller than before
>>>
```

刚才处理整个数据集的方式，仿佛它是一个字典序列，但实际上从未创建或存储字典列表。并非所有问题都能这样组织；不过，只要能以迭代方式处理数据，生成器表达式就可以节省大量内存。
