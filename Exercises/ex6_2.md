# 练习 6.2

*目标：*

- 深入了解作用域规则
- 学习一些作用域技巧

*修改文件：* `structure.py`、`stock.py`

上一练习创建了 `Structure`，使数据结构的定义变得简单。例如：

```python
class Stock(Structure):
    _fields = ('name','shares','price')
```

它可以工作，但 `__init__()` 有些奇怪。例如，`help(Stock)` 无法给出有用的签名，而且关键字参数不起作用。例如：

```python
>>> help(Stock)
... look at output ...

>>> s = Stock(name='GOOG', shares=100, price=490.1)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: __init__() got an unexpected keyword argument 'price'
>>> 
```

本练习将采用另一种方法解决问题。

## (a) 查看局部变量

先定义以下类进行实验：

```python
>>> class Stock:
        def __init__(self, name, shares, price):
            print(locals())

>>>
```

现在尝试运行：

```python
>>> s = Stock('GOOG', 100, 490.1)
{'self': <__main__.Stock object at 0x100699b00>, 'price': 490.1, 'name': 'GOOG', 'shares': 100}
>>>
```

注意，局部变量字典包含传给 `__init__()` 的全部参数。很有意思。现在定义以下函数和类：

```python
>>> def _init(locs):
        self = locs['self']
        for name, val in locs.items():
            if name == 'self': continue
            setattr(self, name, val)

>>> class Stock:
        def __init__(self, name, shares, price):
            _init(locals())
```

这里的 `_init()` 根据传入的局部变量字典自动初始化对象。你会发现，`help(Stock)` 和关键字参数都能正常工作。

```python
>>> s = Stock(name='GOOG', price=490.1, shares=50)
>>> s.name
'GOOG'
>>> s.shares
50
>>> s.price
490.1
>>>
```

## (b) 操作栈帧

上一部分的不足是，`__init__()` 加入 `locals()` 调用后看起来很奇怪。如果愿意操作栈帧，就可以绕过这一点。试试 `_init()` 的这个变体：

```python
>>> import sys
>>> def _init():
        locs = sys._getframe(1).f_locals   # Get callers local variables
        self = locs['self']
        for name, val in locs.items():
            if name == 'self': continue
            setattr(self, name, val)
>>>
```

这段代码从调用者的栈帧提取局部变量。修改后的类定义如下：

```python
>>> class Stock:
        def __init__(self, name, shares, price):
            _init()

>>> s = Stock('GOOG', 100, 490.1)
>>> s.name
'GOOG'
>>> s.shares
100
>>>
```

你现在可能有些不安：没错，刚才编写的函数进入了另一个函数的栈帧，查看它的局部变量。

## (c) 整合

综合前两部分的思路，删除 `Structure` 原来的 `__init__()`，再添加如下 `_init()`：

```python
# structure.py
import sys

class Structure:
    ...
    @staticmethod
    def _init():
        locs = sys._getframe(1).f_locals
        self = locs['self']
        for name, val in locs.items():
            if name == 'self': continue
            setattr(self, name, val)
    ...
```

注意：之所以定义为 `@staticmethod`，是因为 `self` 已从局部变量中获取，无需再作为参数额外传给该方法。这一点确实有些微妙。

现在将 `Stock` 修改为：

```python
# stock.py
from structure import Structure

class Stock(Structure):
    _fields = ('name','shares','price')
    def __init__(self, name, shares, price):
        self._init()

    @property
    def cost(self):
        return self.shares * self.price

    def sell(self, shares):
        self.shares -= shares
```

验证类正常工作，支持关键字参数，并具有适当的帮助签名。

```python
>>> s = Stock(name='GOOG', price=490.1, shares=50)
>>> s.name
'GOOG'
>>> s.shares
50
>>> s.price
490.1
>>> help(Stock)
... look at the output ...
>>>
```

再次运行 `teststock.py` 单元测试，应该至少多通过一个测试。太好了！

现在看起来像是倒退了一大步。类不仅需要 `__init__()`，还需要 `_fields`，才能让 `__repr__()` 和 `__setattr__()` 工作。`self._init()` 也显得很取巧。后面会继续改进，请耐心。
